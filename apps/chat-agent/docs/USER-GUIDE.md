# 使用指南（对话式任务配置）

> 面向使用方（consumer）。页面：控制台 `/space/chat`（左「研究与任务 → AI 助手」）。

## 一句话上手

在输入框里描述**你的数据 + 你的目标**，助手会推荐场景、用卡片收参数、提交作业并给出任务 ID。
不需要记参数名，也不用翻文档。

## 支持的场景

空态预设提示词会按**当前空间启用的能力包**切换：医疗空间只出医疗场景，电力空间只出电力场景。

### 医疗（`med`）

| 你可以这样说 | 助手会配置的场景 | 需要准备 |
|---|---|---|
| 我想对比试验组和对照组的疗效 | 单臂试验外部对照 | 试验方/对照方 + 各自数据产品 + 分层键（如 `<40|M`） |
| 创建一项单臂外部对照注册研究并生成模拟报告 | 注册型单臂外部对照研究 | Protocol/SAP / ATT + 试验方与外部对照数据源 |
| 我有两家医院的数据，想做预测模型 | L4 联邦学习预测 | ≥2 方 + 数据产品 + 预测目标字段 |
| 统计一下两院各年龄段的患病人数 | 队列规模统计 | 数据持有方 + 数据产品（分层键可选） |

### 电力（`power`）

| 你可以这样说 | 助手会配置的场景 | 需要准备 |
|---|---|---|
| 我想预测明天的电力负荷 | 电力负荷预测 | ≥2 方（电网/气象/工业）+ 预测时长（1–168h） |
| 帮我做削峰填谷的需求响应优化 | 需求响应优化 | ≥2 方 + 24 点目标负荷曲线 + 激励预算 |
| 检测一下跨区域的异常用电 | 跨区域窃电检测 | ≥2 个供电局 + 检测周期（≥30 天） |

也可以直接点名场景，或问「这几个场景有什么区别」（助手会给差异表）。

## 界面怎么用

- **会话侧栏**：「新会话」开一条新对话；点历史会话可恢复上下文；`×` 删除。
- **卡片**：下拉选项来自**当前空间的目录**（参与方 / 数据产品）。目录为空时下拉会降级成文本框并提示
  「直接填写 id」——这是有意的：不让一张填不了的卡片把你卡住。
- **提交**：点卡片上的「提交」。提交中会显示「正在执行 submit_xxx…」，这是步骤级进度。
- 快捷键：`Enter` 发送，`Shift+Enter` 换行。

## 常见问题

**Q：提交失败怎么办？**
失败卡下面会自动出现一张**预填过**的卡片（标题「修改后重新提交」），你填过的值都在里面。
改掉有问题的那一项再提交即可，不用从头描述需求。

**Q：为什么助手说「这几个场景可能都合适」？**
描述里有多个场景的关键词。挑一个继续说，或直接点名场景 id。

**Q：试验方和对照方能是同一家吗？**
不能。校验会在提交前拦下并给出原因。

**Q：我的数据会被传给外部 AI 吗？**
不会。出域内容**只有**你的自然语言、场景说明与目录元数据（参与方/数据产品的 id 与名称）。
不带任何患者级数据、原始行或数据产品内容，也不带填过的参数值。若部署未配置 LLM key，
服务走本地确定性回退，**问题文本完全不出域**。

**Q：为什么有些参数我没填就提交了？**
`purpose / applicant / contracts / notBefore / notAfter / minCell` 这类治理字段由服务端补齐，
卡片描述里会明示当前假设（合约、有效期、最小单元格）。
