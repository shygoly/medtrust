# power-catalog

电力协作的数据产品目录。目录只登记元数据；产品属于电力空间，并挂到对应协作。

## ADDED Requirements

### Requirement: 产品属于电力空间

电力数据产品的 `homeSpace` MUST 是电力空间。医疗空间的目录查询 MUST NOT 返回这些产品。缺少 `homeSpace` 的既有产品 MUST 回填到默认医疗空间。已经写明归属的产品 MUST NOT 被改到另一个空间。

#### Scenario: 电力产品不出现在医疗目录

- **WHEN** 请求的空间上下文是医疗空间
- **THEN** 目录结果只含 `homeSpace` 为医疗空间的产品

#### Scenario: 空归属回填到医疗空间

- **WHEN** 启动回填发现 `homeSpace` 为空的数据产品
- **THEN** 该产品归入默认医疗空间

#### Scenario: 已有归属保持不变

- **WHEN** 回填或电力种子遇到 `homeSpace` 已是医疗空间的产品
- **THEN** 该产品的空间归属保持不变

### Requirement: 公开门户不混合两个空间

未携带空间上下文的公开目录 MUST 只返回默认医疗空间的在架产品。

#### Scenario: 匿名门户只有医疗产品

- **WHEN** 未登录访客打开公开目录
- **THEN** 结果中没有电力空间的产品

### Requirement: 未确权不得标成已确权

电力产品在持有方确认权利之前，`rightsConfirmed` MUST 为假。系统 MUST NOT 为这些产品写入虚构的记录条数。行数只有持有方连接器上报统计后才可更新。

#### Scenario: 种子产品未确权且行数为零

- **WHEN** 系统按协作登记一条尚未被持有方确认的电力产品
- **THEN** 该产品未确权，记录条数为 0，且不能作为已授权数据被合约引用

#### Scenario: 未确权产品不能发布为可交易

- **WHEN** 提供方试图把未确权的电力产品发布为可签约产品
- **THEN** 系统拒绝发布

### Requirement: 产品挂到协作并带字段口径

每条电力产品 MUST 关联到提案中的一个应用及其持有方，并带有该融合要素的字段口径。一个产品 MUST NOT 同时属于两个协作。

#### Scenario: 户表产品只属于火灾与其所在协作

- **WHEN** 登记电网持有的楼栋级负荷异常标记产品
- **THEN** 该产品只关联城市用电异常监测，字段口径含楼栋标识与异常标记，不含户表级曲线

#### Scenario: 按协作过滤目录

- **WHEN** 成员打开新能源消纳预测
- **THEN** 只看到该协作关联的产品
