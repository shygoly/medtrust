# 连接器数据产品目录服务（检索 + 详情）

> 上游：NDI-TR-2025-05 §6.3.4（数据产品目录服务，扩展能力）、§7.2（互操作·目录查询：检索服务 / 详情查询）
> 关联：NDI-TR-2025-06（目录元数据字典）

## Why

平台侧有完整目录（`apps/api/src/runtime/catalog`，含生命周期与分类分级），但**连接器侧没有任何对外目录服务**：`apps/connector/src/domain/catalog-resolver.ts` 只做本地解析——把合约/任务里的产品 id 解析成本地数据源，不对外提供检索或详情。

05 把「数据产品目录服务」列为扩展能力，并在 §7.2 明确两类互操作接口：**目录检索服务**与**目录详情查询**。可信数据空间形态下，异构连接器之间要能问"你有什么产品"，不能只靠平台目录代答。

**不做的代价**：任何异构连接器/第三方平台都无法从连接器侧发现产品；送检 §6.3.4 与 §7.2 判缺项。

## What Changes

1. **只读目录端点**（连接器，新增）：
   - `GET /connector/catalog/products`：分页检索，参数限定为白名单（关键词、类型、分级、机构），**不接受任意表达式**
   - `GET /connector/catalog/products/:id`：详情
   - 只回**元数据**：标识（NDI 编码）、标题、类型、分级、记录数量级、字段清单（字段名/类型/描述）、驻留位置、可用状态；**永不返回数据行**
2. **鉴权**：复用 `tc609-p1-connector-cert-auth` 的证书鉴权（指纹 + 签名 + 时间戳防重放），并叠加本地白名单（只允许注册过的对端标识查询）；未鉴权一律 401。
3. **与统一目录一致**：字段字典按 NDI-TR-2025-06；标识按 `ndi-identifier-alignment`。
4. **关闭开关**：`CONNECTOR_CATALOG_SERVICE=off` 时不注册路由（默认 **off**，需要时显式开启）——避免无意扩大院内出站暴露面。

## 不做（范围外）

- 不做数据产品登记/上架/下架的连接器侧写接口（平台侧已有，见 `tc609-data-service-catalog`、`tc609-p1-catalog-lifecycle`）。
- 不做跨连接器直连发现（点对点目录聚合留待互操作检测阶段）。

## 离线可用性（外部未对接时必须成立）

> 现网尚未对接丝路数港。本变更不得把基线抬高为「必须有外部才能跑」。总闸见 [`ndi-external-absent-e2e`](../ndi-external-absent-e2e/proposal.md)。

- **默认 off**：`CONNECTOR_CATALOG_SERVICE` 默认关闭，关闭时路由不注册（404），对现有任务零影响。
- **不新增外网暴露**：开启后仍只服务院内网络，`5022` MUST NOT 发布到院内网之外；部署检查项覆盖。
- **鉴权失败不降级**：未注册对端一律 401，不回退到匿名只读。
- **启动不失败**：开关与白名单缺配置只 `warn`。

## Impact

- 代码：`apps/connector/src/domain/`（新 controller + DTO + 白名单）、`apps/connector/src/mdop/`（鉴权中间件复用）。
- 安全：新增对外端点，必须在院内 DMZ 内网可达而非公网；端口沿用 `5022` 且 `MUST NOT` 发布到院内网之外。
- 风险：元数据也可能泄露病种结构（"某院有 5000 例某罕见病"），字段清单需过 `minCell` 同类抑制判断；只给字段与数量级，不给精确行数。

## 验收

- [ ] 注册过的对端可检索到产品列表与详情；未注册对端 401。
- [ ] 响应体不含任何数据行；快照断言字段白名单。
- [ ] 关闭开关时路由不存在（404）。
- [ ] 精确记录数不外露（只给数量级），有负向用例。
