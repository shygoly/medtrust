## Context

阶段 0 之后，导航清单 `nav.manifest.json` 已是菜单、路由、角色的唯一事实源（D-UI-2），侧栏和布局层门控都读它。分组仍沿用旧的 6 组（声明面/运行面/使用方/合规/运营/管理）。页头标题 21 处写字面量，其中 8 处与菜单名不一致；5 个 admin 页不用 `PageHeader`。

约束：路由地址不变（合并与重定向在阶段 2）；atlas 的第二套设计语言在阶段 3 处理，本阶段不动 atlas 页面内部；不新增依赖。

## Goals / Non-Goals

**Goals:**

- 侧栏每个角色可见不超过 6 项，分区按"用户要做的事"划分。
- 任一非菜单页面一次点击可回到上一级。
- 页面标题与菜单名同源，不再可能漂移。

**Non-Goals:**

- 全局对象检索、空间切换器（计划第 5 节已推迟）。
- 列表与详情合并、路由重定向（阶段 2）。
- 角色化工作台、atlas 设计语言收口、admin 页整体改暗色主题（阶段 3；admin 页本阶段只换页头）。

## Decisions

### 1. 分区即清单的 `groups`，侧栏只列分区

`groups` 改为 6 个分区，各带 `icon` 与 `en`；菜单条目不再带图标。侧栏每个分区一个入口，指向该分区内当前角色可见的第一个页面；没有可见页面的分区不显示。分区内的页面在内容区顶部以局部 tab 呈现，只有一个可见页面时不显示 tab 条。

| 分区 | 页面（tab 顺序） |
|---|---|
| 工作台 | 空间总览 |
| 数据与合约 | 数据产品、数字合约、本院连接器、结算 |
| 研究与任务 | 编排任务、MDOP 作业、联邦密算、模型交付 |
| 合规与监查 | 合规总览、RBQM 监查、合规告警、审计日志、存证账本 |
| 平台 | 用户管理、机构认证审核、系统状态、基础设施、丝路数港互认 |
| 能力与准入 | 能力图谱、合规预审、密算编排 |

结算放在"数据与合约"：它是合约条款的兑付，与产品、合约构成同一条商业链。存证放在"合规与监查"：它是审计凭据。两者都只是清单里一个字段，可随时调整。

备选：侧栏保留两级（分区标题 + 全部子项常显）。否决，因为项数不变，只是换了分组名。

### 2. 面包屑与 tab 由布局统一渲染

新增 `components/console/section-bar.tsx`，挂在 `(console)/layout.tsx` 的 `main` 顶部、`RouteGuard` 之外。面包屑 = 分区 / 菜单页 / 父链上的各级页面，由清单 `parent` 链生成；动态路由的参数值从当前路径取。子页面的参数与父页面不同名时（推理页 → 任务详情），若两者各只有一个参数则复用其值；需要附带查询串的由条目的 `parentQuery` 声明。

页面不需要改任何代码即获得面包屑，所以不设"详情页必须有面包屑"的守护规则。

### 3. 命令面板不走 portal、不加依赖

`components/console/command-palette.tsx` 自绘固定层，渲染在 `.cs` 作用域内（shadcn `Dialog` 走 portal，会丢失 `--cs-*` 令牌）。⌘K / Ctrl+K 开合，方向键选择，回车执行，Esc 关闭；侧栏顶部有带快捷键提示的触发按钮。

命令全部由清单推导，纯函数放在 `lib/nav.ts`：

- 跳转：当前角色可见的菜单页。
- 动作：当前角色可见的静态表单页（发起任务、发起 RWS 任务、发起 L4 联邦预测）。
- 按 ID 直达：输入不匹配任何命令时，对每个"单参数详情页"给出"打开{页面名} {输入}"。

计划里的"签发合约""导出审计"是页面内按钮而非路由，本阶段以跳转到所在页面代替，不做跨页触发。

### 4. 页头标题缺省取清单 label

`PageHeader` 的 `title` 改为可选，省略时渲染 `NavTitle`（客户端组件，按当前路径取条目 label）。静态路由页面删除字面量标题；动态详情页仍可传入对象自身的标题。目录页按模式切换标题，保留表达式写法。

守护新增 N9：静态路由条目的页面目录内，`PageHeader` 不得带字符串字面量 `title`。只查标签自身的属性，不误伤 `action` 槽内子元素的 `title`。

标题与菜单名不一致的 8 处一律取菜单名（如"上链存证"→"存证账本"、"本院节点"→"本院连接器"）。

### 5. 发起任务表单限定 consumer

`POST rws/tasks` 与 `POST fl-prediction/tasks` 在服务端是 `consumer` 专属。三个表单页在清单里加 `roles: ["consumer"]`，两个具体表单加 `guards`，由阶段 0 的布局层门控和 N6 规则接管。

## Risks / Trade-offs

- 侧栏项数骤减，老用户要重新找入口 → ⌘K 可直接搜旧菜单名；tab 保留原名称。
- 合规方、提供方在"合规与监查"下看到的 tab 数量不同（提供方只有存证账本）→ 单 tab 时隐藏 tab 条，面包屑仍标明所在分区。
- atlas 页面顶部出现 console 风格的面包屑与 tab，与页面内部的 atlas 风格并置 → 阶段 3 收口；本阶段截图确认可读即可。
- admin 页只换页头，正文仍是浅色主题样式 → 记为已知不一致，随阶段 3 处理。
- 标题改名会让已有截图、演示话术与界面不一致 → 上线后重截。

## Migration Plan

纯前端改动，无数据迁移，路由不变。回滚 = 回退提交。
