# 本地端到端运行证据（疫苗真实世界保护效果 · 检测阴性设计）

> **等级**：A（机器可复核的 JSON 输出，可一条命令复跑）。
> **边界（必须逐处标注）**：合成数据；检测记录与 VE 真值均为**注入**，不代表任何疫苗的真实保护效果。
> 本记录**不是** TDX 真跑——它跑的是本地节点组件（真 wasm 模块字节、真沙箱、真发布审查），
> TDX 内执行与链上锚定另见 `tdx-attestation-pilot` 的证据。

## 复跑

```bash
# 1) 数据（Synthea 基座 + 注入层）
node scripts/build-ve-records.mjs --synthea data/synthea/rws-showcase/csv --out data/demo/ve
# 2) 模块字节（可复现构建）
pnpm --filter @medtrust/wasm-algorithms build
# 3) 本地端到端（本目录产物即由此生成）
pnpm --filter @medtrust/connector demo:rws-scenarios
```

## 这份运行做了什么

```
Synthea 合成人群（接种史，真实抽取）
  → 疾控侧封存投影 ve-registry（白名单内疫苗、一剂一行）
  → 医院侧封存投影 ve-tests（白名单内病原、同人同日重复检测本地去重）
  → 节点内 ve-tnd.wasm（SM3 98c84695…dbe8，382B，只导入 env.memory）
  → 发布审查 declassify.small_cell（minCell=5）
  → C3 出域载荷（逐层 2×2 + 部分免疫单列 + buckets）
```
