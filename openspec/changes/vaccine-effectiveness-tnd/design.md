## Context

- 已有能力（AEFI 场景已真跑）：MDOP 作业 → C2 封装（`seal.envelope`）→ 可信空间节点（teeA，阿里云 g8i Intel TDX）
  → 会话证明（TDX quote V5，Intel PCS 背书链）→ 校验方/试点 KMS（teeB）按证明释放密钥 → 节点内 Wasm 执行
  → 发布审查（minCell）→ C3 出域 → 回执链上链（长安链）→ 销毁。
- 算子框架：AssemblyScript Wasm，宿主把对齐/分层结果写成**纯数字列**，模块只见数字（见 `modules/scri-as`、
  `modules/distinct-count-as`）；TS 参考模型与模块**同夹具对拍**（漂移即测试红）。
- AEFI 的 SCRI 只回答「有没有害」；保护效果（VE）是同一批数据的另一半问题，且**纳入条件更依赖跨机构日期**。

## Goals / Non-Goals

**Goals:**
- 在既有 C2 链路上增加第二个「协同计算做不到、TEE 能做到」的真实场景：疾控 × 医院的**检测阴性设计 VE 估计**。
- 全链真跑：真实 TDX quote、真实密钥释放、节点内真实 Wasm 模块、结果与答案键逐格一致、销毁 + 上链。
- 结果解读可用且不误导：VE 与区间、各层方向由**确定性计算**给出，模型只转述；结论说反即拒收。

**Non-Goals:**
- 不做真实疫苗保护效果结论；数据全部合成，效应量为注入。
- 不做随时间变化的 VE（waning）、不做疫苗株匹配、不做多病原合并、不做负对照结局校正。
- 不做倾向评分/加权；不做机密推理（模型不进 TDX）；不做生产 KMS。

## Decisions

### D1 选检测阴性设计（TND），不选全人群队列
| 维度 | 队列（全人群） | **TND（选定）** |
|---|---|---|
| 分母 | 需要全人群观察人时（疾控/医院都没有干净分母） | 只在「因该病就诊并检测」的人内比较 |
| 就医行为混杂 | 严重（接种者更可能就医/检测） | 阳性与阴性两组都已就医，倾向被对齐 |
| 与 C2 的契合 | 需要人时与协变量，跨机构交换更多 | 只需「接种日期 + 检测日期 + 结果」的逐人判定 |
| 业界地位 | 可行但需强校正 | 疫苗有效性观察性研究通行设计 |

> TND 的已知代价：只能估计「对**已就医并检测**人群的保护效果」，且要求检测敏感度在接种/未接种间无差异
> （事实清单固定声明）。

### D2 免疫状态与窗口定义
- **已接种**：检测日前 **≥14 天**完成末剂接种（免疫建立期后）。
- **部分免疫**：检测日前 1–13 天接种 → **单列**，不计入主分析（模板与结果页均标注）。
- **未接种**：检测日前无任何目标疫苗记录。
- 分层键：`ageBand × sex`（主分析）、`doses`（1 剂 / ≥2 剂）作为并列分层维度（可选第二张表）。
- 多次检测：同一人多次检测**各次独立计入**（TND 惯例）；模板限定「一次就诊一次检测」由投影层按
  `(linkKey, 检测日期)` 去重，避免同次就诊重复计数。

### D3 为什么必须 TEE（选型依据，写进对外物料）
| 方案 | 能否做 | 原因 |
|---|---|---|
| 数据不出域 / 协同计算 | 否 | 判定「检测日 − 末剂接种日 ≥ 14 天」需逐人把两机构日期放在一起；疾控无检测日期、医院无接种日期，任何一方单独算不出纳入集，只能交换行级日期（C0）——越线。 |
| 联邦学习 | 否 | 不是训练问题；本场景是**纵向逐人连接 + 分层 2×2 计数**。 |
| MPC | 理论可、工程不可行 | 隐私连接 + 逐对日期比较 + 分层计数，电路随分层/设计变更重写；试点资源下不可接受。 |
| TEE（C2） | 是 | 两方只封最小投影进 TDX，节点内对齐与计数，只出过闸聚合（C3）。 |

### D4 最小投影 + 编码白名单（封装阶段）
- 疾控封 `ve-registry`：`{linkKey, ageBand, sex, immunizations[{vaccineCode ∈ vaccineCodes, doseNo, date}]}`。
- 医院封 `ve-tests`：`{linkKey, ageBand?, sex?, tests[{pathogenCode ∈ pathogenCodes, date, result ∈ {pos,neg}}]}`。
- 关联假名 `linkKey` 由各机构用同一把盐从身份标识派生（与 AEFI 同一演示口径：`sha256(盐‖源标识)` 前 20 位）；
  院内假名 `subjectKey` 彼此不同、不出院。**不在白名单的疫苗与检测（含其它病原、其它就诊）不出机构。**
- 分层键（ageBand/sex）若医院缺失，MUST 由医院侧本地补全或由模板声明「该分层不可用」——不得在节点内回填明文。

### D5 模块 ABI `ve-tnd@1`（实现口径）
- 分工按既有算子惯例（与 `scri` 同形）：**宿主（节点侧编码）做跨机构对齐**——按 `linkKey` 把疾控的接种记录与
  医院的检测记录配到同一个人、取「检测日当天或之前最后一剂」、算出间隔 `gap = 检测日 − 该剂接种日`
  （该人检测日前无目标疫苗 → 哨兵 `INT32_MIN`）、做分层编号映射；**模块只按 `gap` 分格计数**。
- 头部 i32：`[immuneDays]`（免疫建立期天数，≥1，模板参数化；演示 14）。
- 输入列：`i32 gapDays[n]`、`u8 result[n]`（1 阳 / 0 阴）、`u8 stratum[n]`。
- 输出：`k × {vaccPos, vaccNeg, unvaccPos, unvaccNeg, partialPos, partialNeg}`（u32，24 字节/层）。
- 分格：`gap = 哨兵` 或 `< 0` → 未接种；`gap ≥ immuneDays` → 已接种；`0 ≤ gap < immuneDays` → 部分免疫。
- 返回码：`0` 成功 / `3` 分层编号越界 / `5` 参数非法（`immuneDays < 1`、`n < 0`、`k < 1`、`result ∉ {0,1}`）。
- **主体键、日期文本、编码文本一律留在宿主**；`partial*` 不计入主分析但必须输出以便审计。
- 零能力：只导入 `env.memory`，不导入任何函数/表/全局量，不调用 WASI（`check-reproducible` 逐模块校验）。
- **实测（2026-10-03）**：`ve-tnd.wasm` **382 字节**，SM3 `98c84695bb79ba94a1173a86858a51f6162d0010f723d71fe42f510d2550dbe8`，
  abi 1；8 项对拍全绿（`scripts/ve-tnd-parity.test.mjs`）；算子登记 `rws.ve-tnd@1.0.0`
  （`category: collab`、`environments: [tee]`、输入 `accept_labels: [C2]`）。

### D6 发布审查口径
- 每层 `buckets[].count = min(非零的 vaccPos, vaccNeg, unvaccPos, unvaccNeg)`；按 minCell（演示 5）判；
  任一格偏小 → **整层抑制**，抑制层所有数值字段置零。
- **不出合计**（合计 − 未抑制层 = 被抑制层，会反推小细胞）。
- 若某层 `vaccPos = 0` 或 `unvaccPos = 0`（无事件），该层 VE 不可估：结果页 MUST 显示「不可估计」而非 0 或 100%。

### D7 统计量（服务端确定性计算，模块只出计数）
- 层内：`OR = (vaccPos × unvaccNeg) / (vaccNeg × unvaccPos)`，`VE = 1 − OR`。
- 区间：Woolf 法 `SE(lnOR) = sqrt(1/a + 1/b + 1/c + 1/d)`，`lnOR ± 1.96·SE` → 取反对数 → `VE` 区间
  = `[1 − OR_hi, 1 − OR_lo]`。零格时 MUST 用 **Haldane-Anscombe 校正（各格 +0.5）** 并标注「已校正」。
- 汇总（可选）：固定效应逆方差合并各层（Mantel-Haenszel 作为对照），仅在 ≥3 层可估时给出，标注方法。
- **结论前置**：事实清单第 3 行放确定性归纳（「N 个可估分层中，X 层 VE>0 且区间不含 0；…」）；
  `contradictedVerdicts()` 扩展方向词（`保护/有效/VE>0` vs `无保护/无效/未见`），草稿与事实清单方向矛盾 → 422 拒收。

### D8 合成数据：Synthea 接种史 + 注入检测结局
- 人口基座：复用 `data/synthea`（6892 人）与 AEFI 的接种史抽取（CVX 码 + 日期）；
- 检测记录注入：每个「因目标病就诊」的人按接种状态抽样结果——
  `P(阳性 | 已接种) = π₀ × (1 − VE_true)`、`P(阳性 | 未接种) = π₀`，`π₀`（未接种阳性率）取 0.35（为统计功效放大）；
- 分层：`ageBand × sex` 若干层；**只在中青年层注入 VE_true = 0.6**，老年层注入 `VE_true = 0`（负例层），
  用于验证「分层可分辨」与「不可估计层」两种边界；
- 部分免疫（1–13 天）与「检测前无接种」样本按固定比例注入，作为纳入条件判定的对拍点；
- 答案键：与算子**同一口径**计算每层 2×2 与真 VE，落盘供逐格对拍；全部数据标注合成来源（`rws-test-data-injection` 口径）。

## Risks / Trade-offs

- [注入效应量被误读为真实保护效果] → 物料每处标注「合成数据 + 注入效应量，不代表任何疫苗真实保护效果」；
  红线以 `tdx-attestation-pilot/external-claims.md` 为准。
- [TND 假设不成立（检测敏感度差异、就医行为残留）] → 事实清单固定声明假设与局限；生产需敏感性分析
  （阴性对照结局、不同免疫建立期 7/14/21 天）。
- [小细胞抑制使分层不可解释] → 结果页并列「抑制层数」；不得为可解释性放宽 minCell。
- [零格导致 VE 不可估/极端值] → Haldane-Anscombe 校正 + 「已校正」标注 + 「不可估计」显式呈现。
- [结论回查是关键词规则，不是语义理解] → 只拦明确矛盾；事实清单与草稿并列，草稿标注「待研究者确认」。
- [查询预算] → 每次真跑扣疾控数据集预算；演示重跑次数受限（沿用既有预算台账）。
