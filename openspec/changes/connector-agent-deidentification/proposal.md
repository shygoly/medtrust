# 院内脱敏下沉：connector 调用 Python agent 执行平台下发的脱敏规格

> 上游：TRUST.md（数据最小化 / 本地留存）· DOMAIN.md（脱敏与假名化）· `docs/omop-cdm-onboarding.md`（数据源接入）
> 现状：脱敏在连接器 TS 内做（`apps/connector/src/domain/deidentifier.ts`），固定几条规则、盐写死缺省值；agent 已是院内计算后端（gRPC `:5024` + `x-agent-token`），但只承接因果/联邦训练，不承接脱敏。
> 触发：数据体量大（千万行级）、自由文本去标识（需要 Python 生态）、以及"脱敏算法应由平台统一下发、不得各院各写一套"的治理诉求。

## Why

1. **大表过连接器进程不划算**：结构化的千万行级队列在 Node 进程里逐行变换，内存与 CPU 都是瓶颈；连接器把按 D-CN-6 裁剪后的投影块流给同院 agent，agent 不持有数据源凭据。
2. **自由文本去标识做不了**：病历文本里的姓名/地址/电话/住院号，需要 NER + 词典 + 规则组合，Python 生态成熟；现有 `Deidentifier` 只覆盖结构化直接标识。
3. **脱敏口径必须统一**：现在各家连接器各写一套规则（盐缺省值还写在代码里），同一份数据在不同院脱敏结果不可比，跨院对齐与重识别评估都无法做。平台统一下发**签名规格**，才能保证口径一致且可审计。
4. **脱敏是前置义务，不是出域闸门的替代**：脱敏做得好坏直接决定后续重识别风险；它必须与合约条款绑定（"保留到年龄带 / 哈希加盐 / 抑制小格"），而不是实现方自选。

## What Changes

1. **新增脱敏规格（DeidSpec）**：声明式 JSON + 固定算子集（哈希加盐 / 泛化 / 抑制 / 日期偏移 / 值域映射 / 截断 / 假名化 / 自由文本规则），由平台签发（注册中心密钥，复用 CTL-26 三钥分离）。
2. **新增 agent 脱敏服务**：`packages/proto/deidentify.proto`（gRPC，沿用 `AGENT_GRPC_URL` 与 `x-agent-token`），agent 侧只执行**内置实现**的参数化变换，**不执行任意代码**。
3. **连接器侧编排**：合约 → 取规格 → 验签/吊销/降级检测 → 调 agent → 校验回执（摘要 + 行数 + 规格摘要）→ 结果进本地存储。连接器仍是唯一控制点。
4. **盐与密钥归医院**：规格只引用 `salt_ref`，agent 在本机 KMS/Vault 取盐；平台既不下发盐也不接收。
5. **审计与回执**：agent 写本地审计链并回摘要；连接器落审计并可选锚定；响应**不含任何数据行或样本**。
6. **开关与兼容**：`CONNECTOR_DEID_MODE=builtin|agent`（缺省 `builtin`）。启用 `agent` 后连接器**不得**绕过 agent 自行脱敏。

## 不做（范围外）

- **不下发可执行 Python 代码**（v1）：那等于给平台开一条 RCE 通道。自由文本 NER 先走"内置算法 + 词典/模型参数"，插件化放到 Phase 2 并复用 WASM 模块同一套准入（SM3 + 签名 + 吊销 + 沙箱）。
- **不做跨院可对齐假名**（OPRF/共管密钥）：跨院去重与配对需要它，但那是独立的密钥治理决策，另立项。
- **不替代出域闸门**：脱敏后的产物仍需过 `minCell` / `minCellRare` / 行级拦截。
- **不改变"原始数据不出院"**：agent 与连接器同处院内；平台只收到回执与聚合结果。

## Impact

- 代码：`packages/proto/deidentify.proto`、`apps/agent/src/medtrust_agent/deidentify_servicer.py`、`apps/connector/src/domain/deid/`（client + spec 校验 + 编排）、`apps/api`（规格签发与管理端点）。
- 数据：新增规格版本表（`cp_deid_spec`，含签名与吊销状态）；不改现有产品/合约结构。
- 部署：agent 侧内存/CPU 需求上升（大表）；见 `docs/deploy/部署硬件需求-v2.md` §4.5.1 的加大选项。
- 风险：agent 成为新的数据入口，必须与 `LocalStore` 同等级守卫（无外部读路径、无样本外传）；规格降级（把"哈希加盐"改成"原样"）要有显式拒绝用例。

## 验收

- [ ] 同一份 golden corpus，`agent` 模式与 `builtin` 模式在结构化字段上输出一致（迁移期回归）
- [ ] 规格被篡改 / 已吊销 / 与合约要求不一致（降级）→ 任务 fail-closed，且**不退回**内置弱脱敏
- [ ] 响应体不含数据行或样本（字段白名单断言）；`row_limit` 超限即拒
- [ ] 盐缺失或 `salt_ref` 无效 → DENIED（不生成确定性恒等假名）
- [ ] 回执可复算：`input_digest` / `output_digest` / `spec_sm3` 与连接器侧记录一致
- [ ] 自由文本样例中直接标识（姓名/电话/住址/住院号）零残留（Phase 2 起）
