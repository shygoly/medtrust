# 本地端到端运行证据（跨院去重的发病率与罕见病登记）

> **等级**：A（机器可复核的 JSON 输出，可一条命令复跑）。
> **边界（必须逐处标注）**：合成数据；**跨院重复比例是注入的**、**罕见病患病率已放大 10 倍量级**、
> 事件发生率按分层放大 10 倍，均不代表任何真实人群的发病率或跨院就诊比例。
> 本记录**不是** TDX 真跑——TDX 内执行与链上锚定另见 `tdx-attestation-pilot` 的证据。

## 复跑

```bash
# 1) 数据（Synthea 基座 + 注入层）
node scripts/build-dedup-records.mjs --synthea data/synthea/rws-showcase/csv --out data/demo/dedup
# 2) 模块字节（可复现构建）
pnpm --filter @medtrust/wasm-algorithms build
# 3) 本地端到端（本目录产物即由此生成）
pnpm --filter @medtrust/connector demo:rws-scenarios
```

## 这份运行做了什么

```
Synthea 合成人群（人口基座）
  → 两院各自封存投影 dedup-cohort（白名单内事件/罕见病；无假名或无观察期不出院）
  → 节点内 dedup-incidence.wasm（SM3 02f0f409…7a75，1019B，只导入 env.memory）
      人头并集 · 观察期区间并集（可填 1 天边界空隙）· 事件按（人, 码, 日期）去重 · 罕见病按人取最早
  → 发布审查：minCell=5（常规）+ minCellRare=10（**罕见病列单独抑制**）
  → C3 出域载荷（四项计数 + buckets + rareBuckets）
```

## 关键数字（本次运行）

| 项 | 值 |
|---|---|
| 两院 | 甲院 **4038** 人 / 乙院 **3646** 人 → 跨院去重后合计 **6354** 人 |
| 观察期 | 注入**部分重叠 663 例**、**空 1 天 667 例** |
| 事件 | 注入 **18 起跨院重复记录**（同码同日，去重后只算一次） |
| 罕见病 | 注入 165 例（含两院重复登记；去重后按人计） |
| **直接相加的虚增** | 人头 **+19.5% ~ +23.3%** · 罕见病 65+ 层 **+24.6% / +33.3%** |
| 罕见病列单独抑制 | 18-39\|F、40-64\|F、40-64\|M 三层（2/2/5 例 < 10）→ 罕见病列置零并标 `rareSuppressed`，**其余列照常发布** |
| 65+ 层保留 | 65+\|F **87 例**、65+\|M **69 例**（≥ 10） |

粗发病率与 Poisson 精确区间（每 10 万人年）逐层见 `dedup-incidence-run.json`。
