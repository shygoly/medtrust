## Context

- 已有能力（AEFI / VE 场景共用）：MDOP 作业 → C2 封装 → 可信空间节点（teeA，阿里云 g8i Intel TDX）
  → 会话证明（TDX quote V5，Intel PCS 背书链）→ 校验方/试点 KMS（teeB）按证明释放密钥
  → 节点内 Wasm 执行 → 发布审查（minCell）→ C3 出域 → 回执链上链（长安链）→ 销毁。
- 已有算子：`disproportionality`（四格失衡）、`distinct-count`（**按分层去重主体数**）、`pairing`（PSI 配对）、
  `scri`（自身对照风险期）、`ve-tnd`（检测阴性设计，见在途变更）。
- `distinct-count` 已能回答「去重后有多少人」，但**回答不了人时与事件去重**：同一患者在两院的观察期
  重叠部分不能相加，同一事件被两院各记一次也不能算两次。本场景补上这两块，并叠加罕见病登记的高风险口径。

## Goals / Non-Goals

**Goals:**
- 在既有 C2 链路上增加第三个场景：**多院去重的发病率**与**罕见病登记**，且把「去重前后差多少」作为结论的核心证据。
- 全链真跑：真实 TDX quote、真实密钥释放、节点内真实 Wasm、结果与答案键逐格一致、销毁 + 上链。
- 罕见病口径从严：更严 minCell、抑制层如实呈现、不因「想看到数字」而放宽。

**Non-Goals:**
- 不做真实流行病学结论；跨院重复比例与罕见病患病率均为**注入**，不代表任何真实人群。
- 不做假名质量/连接误差的个体级评估（`linkKey` 断裂或碰撞的影响另立项）。
- 不做差分隐私保证（本场景只有 minCell 抑制与小细胞置零）。
- 不做跨院生存分析、不做地区代表性推断、不做时间趋势的年龄-时期-队列建模。

## Decisions

### D1 去重口径三件套（节点内强制，模板声明）
| 对象 | 口径 | 为什么不能各院自行处理 |
|---|---|---|
| **人头** | 按 `linkKey` 取并集 | 各院只知道本院是否有此人，交集/并集都无法单独算出 |
| **人时** | 同一 `linkKey` 的观察期**取区间并集**（合并重叠与相邻区间） | 重叠期相加会灌水分母；各院不知道对方起止，无法裁剪 |
| **事件** | 按 `(linkKey, 事件码, 事件日期)` 去重 | 同一次事件可能被两院各记一次（转诊/复查），相加即重复计数 |
| **罕见病** | 首次诊断取**最早日期**，按人去重计数 | 两院各登记一次会把「1 例」变「2 例」，罕见病统计效力全在小计数上 |

- 「相邻区间」（前一段 end 与后一段 start 相差 ≤ 1 天）MUST 合并，避免因入院/出院日边界产生 1 天空隙。
- 口径参数（是否合并相邻、观察期是否裁剪到研究窗口）由模板声明并写入作业记录，MUST NOT 由各院自定后相加。

### D2 为什么必须 TEE（选型依据，写进对外物料）
| 方案 | 能否做 | 原因 |
|---|---|---|
| 数据不出域 / 协同计算 | 否 | 去重需要「同一人是否在多院」的全局视图；人时并集需要同一人多段观察期的相互位置。任一方都只有局部，只能交换行级记录（C0）——越线。 |
| PSI（隐私集合求交） | 部分 | 能给出交集大小与成员，但 ① 本场景要的是**并集**口径的人头；② 给不出**人时并集**与**事件去重计数**；③ **成员资格本身就是行级信息**（某人是否跨院）→ 参与方即可反推个体跨院事实。 |
| MPC | 理论可、工程不可行 | 集合上的区间合并 + 逐人事件去重 + 分层计数，电路随口径变更重写；且参与方得到的中间结果仍可能泄露成员资格。 |
| TEE（C2） | 是 | 各院只封最小投影进 TDX，节点内做并集/去重/计数，**只出过闸聚合（C3）**；参与方拿不到任何成员资格信息。 |

### D3 模块 ABI `dedup-incidence@1`（实现口径）
- 分工：**宿主（节点内编码）**做窗口裁剪、白名单过滤、罕见病按（层, 主体）归并取最早、
  主体/事件键的整数映射，并把三组列**排序**；**模块**只做线性扫描的区间并集 / 事件去重 / 计数
  （不排序、不分配堆、不导入任何函数）。
- 签名：`run(inOff, n, k, outOff)`，其中 `n = nObs + nEvents + nRare`（模块校验）。
- 头部（4 × i32）：`[nObs][nEvents][nRare][mergeAdjacent]`；**研究窗口在宿主侧裁剪**，不进模块。
- 列（顺序固定；u8 列之后按 4 字节对齐，宿主与测试用同一算法计算偏移）：
  `subjectObs u32[nObs]` · `stratumObs u8[nObs]` · `startDay i32[nObs]` · `endDay i32[nObs]` ·
  `subjectEv u32[nEvents]` · `stratumEv u8[nEvents]` · `eventKey u32[nEvents]` ·
  `subjectRare u32[nRare]` · `stratumRare u8[nRare]`。
- 输出：`k × {uniqueSubjects, personDaysUnion, eventsDeduped, rareCases}`（u32，16 字节/层）。
- **排序契约**（模块校验；违反即返回 `6` 拒绝——宁可拒绝，也不给出悄悄算错的结果）：
  观察列按 `(stratum, subject, startDay)`、事件列按 `(stratum, subject, eventKey)`、
  罕见病列按 `(stratum, subject)` **非降序**。
- 合并判据：`mergeAdjacent = 1` → 允许填补 **1 天**边界空隙（`start ≤ curEnd + 2`）；
  `0` → 只并重叠/紧邻段（`start ≤ curEnd + 1`）。实测：中间空 1 天的两段，并集人日 **302 → 301**。
- 返回码：`0` 成功 / `3` 分层编号越界 / `5` 参数非法（计数为负、与 `n` 不符、`start > end`、
  `mergeAdjacent ∉ {0,1}`）/ `6` 排序契约被破坏。
- 宿主回填后校验不变量：① `uniqueSubjects ≤ 该层观察行数`；③ `Σ_k uniqueSubjects ≥ 全量去重主体数`；
  ④ `eventsDeduped ≤ 该层事件行数`；⑤ `rareCases ≤ uniqueSubjects`。
- 零能力：只导入 `env.memory`，不导入函数/表/全局量，不调用 WASI（`check-reproducible` 逐模块校验）。
- **实测（2026-10-03）**：`dedup-incidence.wasm` **1019 字节**，
  SM3 `02f0f409c65c93ccd2bd36c3662cc02fd52d7c416c999ed774e61a4f86c67a75`，abi 1；
  8 项对拍全绿（`scripts/dedup-incidence-parity.test.mjs`）；算子登记 `rws.dedup-incidence@1.0.0`
  （`category: collab`、`environments: [tee]`、输入 `accept_labels: [C2]`）。

### D4 最小投影 + 编码白名单（封装阶段）
- 各院封 `dedup-cohort`：`{linkKey, ageBand, sex, observation{start,end}, events[{code ∈ eventCodes, date}],
  rareDisease{code ∈ rareCodes, firstDate} | null}`。
- 关联假名 `linkKey` 由各院用同一把盐从身份标识派生（演示口径同 AEFI/VE）；院内假名 `subjectKey` 不出院。
- 白名单外的诊断/事件、以及**非研究窗口内**的观察期 MUST 在本地裁剪并留审计，MUST NOT 进载荷。

### D5 发布审查：双阈值 + 整层抑制 + 不出合计
- 每层 `buckets[].count = min(非零的 uniqueSubjects, eventsDeduped, rareCases)`，与 `minCell`（演示 5）比较；
- **罕见病另设 `minCellRare`（默认 10）**：当层的 `rareCases > 0` 且 `< minCellRare` → 该层**罕见病列单独抑制**
  （置零并标注），其余列按 `minCell` 判；
- MUST NOT 输出任何跨层合计；结果记明抑制层数与两个阈值取值。

### D6 统计量（服务端确定性计算）
- **粗发病率** = `eventsDeduped / (personDaysUnion / 365.25) × 100,000`（每 10 万人年）；
- **区间**：Poisson 精确区间（事件数 k 的精确区间换算到率；k = 0 时用单侧上界），MUST 标注方法；
- **去重前后对比**（本场景的核心证据，必须报告）：同时给出「各院直接相加」的口径值
  （`Σ_k 各院人头/人时/事件` 的聚合并值）与「节点内去重后」的值，以及**虚增比例**；
  两个口径**都必须过闸**（对比值同样是聚合，不得借对比之名放行小细胞）；
- **直接标准化率**（可选）：按年龄组标准化到给定标准人口；权重 MUST 为部署参数、MUST NOT 进节点；
- 罕见病登记：给出**去重后例数**与（能否给出的）分层分布，被抑制层如实标注。

### D7 合成数据：两院切片 + 跨院重复注入 + 罕见病注入
- 人口基座：`data/synthea`（6892 人）按固定种子切片为两院队列（如 60% / 55%，重叠 ~20%）；
- **跨院重复注入**：重叠患者在两家各有观察期，其中一半**观察期部分重叠**、一半**相邻**（验证合并口径）；
- **事件注入**：常见结局按分层注入基础发生率；其中一部分事件在两院**各记一次**（验证去重）；
- **罕见病注入**：目标罕见病按 `1/10000` 量级注入并按统计功效**放大到可测**（如实标注放大倍数），
  确保至少一层 `rareCases ≥ minCellRare`、另有一层 `< minCellRare`（验证双阈值）；
- 答案键：与算子同口径计算每层 `uniqueSubjects / personDaysUnion / eventsDeduped / rareCases`、
  直接相加口径值、以及真虚增比例。

### D8 如实边界（写进事实清单与物料）
- 事实清单 MUST 含：「跨院重复比例为注入」「罕见病患病率已放大 N 倍」「合成数据，不代表任何真实人群」；
- **禁止表述**：「某地发病率是多少」「某罕见病在中国有多少例」——只能说「在本合成队列上，直接相加会虚增 X%」；
- 抑制层 MUST NOT 通过对比值、分层差或时间趋势被反推（对比值同样过闸）。

## Risks / Trade-offs

- [注入的重复比例被当作真实跨院重叠率] → 事实清单与物料逐处标注注入比例与放大倍数。
- [人时并集口径分歧] → 模板声明口径（合并相邻、窗口裁剪）并写进作业记录；对拍夹具覆盖重叠/相邻/跨窗口三种。
- [罕见病双阈值导致大量抑制、结果不可读] → 如实呈现「被抑制层数」，并用去重前后对比承担主要结论；
  MUST NOT 为可读性放宽 `minCellRare`。
- [假名质量决定去重正确性] → 本场景不评估连接误差；事实清单声明「去重正确性依赖各院假名一致」，
  假名质量另立项（与 `participant-identity` 关联）。
- [直接相加对比值本身泄露] → 对比值计入同一发布审查；小细胞层两侧同时抑制。
- [查询预算] → 每次真跑扣参与院数据集预算（沿用既有预算台账）。
