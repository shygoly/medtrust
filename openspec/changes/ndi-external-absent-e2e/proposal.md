# 外部缺失总闸：无丝路数港环境下的全链路回归

> 覆盖变更：`ndi-platform-state-report`、`ndi-identifier-alignment`、`ndi-connector-catalog-query`、`ndi-catalog-upstream-listing`、`ndi-usage-control-engine`
> 背景：2026-11-05 仍未对接丝路数港；现网基线是「按能力 fail-closed、主链路可跑」。本变更把这个基线固化成**可执行的总闸**。

## Why

上面五个变更分别触碰了**对外上报**、**标识映射**、**新增对外端点**、**发布校验**、**任务执行前的策略判定**。它们单独看都有降级开关，但缺一条能一次性证明「外部不存在时系统照样跑完一条业务」的回归：

- 每个人靠记忆保证「没有外部也不影响」，迟早破。
- 外部不通有两种形态：**未配置**（fail-closed 的显式错误）与**配置了但不可达**（超时/500）。后者更容易把超时预算传染给业务线程。
- 产品校验类改动（服务规格、公开授权）会在**本地**产生回归，与外部无关，也需要同一条链去跑。

**不做这个总闸的代价**：任何一次「顺手加个上报」都可能让任务领不到、目录改不动，而单元测试发现不了。

## What Changes

1. **新增 e2e 套件**（`apps/api` + `apps/connector` 联跑）：`SILKROAD_NODE_ENDPOINT` 为空、`NODE_ENV=production` 的形态下跑完整业务链，断言主链路全绿、互认端点返回明确 503。
2. **两种外部形态各跑一遍**：
   - A「未配置」：`SILKROAD_NODE_ENDPOINT=''` → 互认端点 503；主链路 200。
   - B「配置了但不可达」：指向一个必然超时的地址（如 `http://127.0.0.1:1`）→ 互认端点超时失败；**任务领派与链路耗时不受影响**（对长轮询耗时加断言上限）。
3. **用例清单**（每条都要有明确断言，不做「跑通即过」）：
   - 登录 → 目录发布（含一个 `service` 类型产品）→ 分类分级校验
   - 合约：申请 → 批准 → 备案回执（链在本地，不依赖外部）
   - RWS L1.5/L3 任务：连接器领任务 → 执行 → C3 回传 → 结算
   - MDOP 作业：提交 → 要约 → 连接器复核 → 凭证 → 执行 → 回执
   - 存证：写入 → 按哈希查验（自建链形态）
   - 审计：链路完整性校验
   - 目录上报：`pushCatalog` 在 A 形态下返回明确错误、在 B 形态下失败但本地目录仍可读写
4. **契约化断言（六条安全垫）** 固化为测试名，任何一条失败即总闸红：
   - 迁移只加列（schema 快照对比）
   - 启动在外部缺失时成功（只 warning）
   - 后台上报使用 noop 而非 fail-closed client（装配断言）
   - 对外动作与业务动作预算隔离（长轮询耗时上限）
   - 存量数据 grandfather（既有 service 产品仍可更新）
   - `USAGE_CONTROL_ENGINE=legacy` 下 PEP 行为不变
5. **跑法与门禁**：新增 `pnpm test:e2e:no-external`；这五个变更的 PR 必须附一次运行结果。默认 `pnpm test` 不挂它（需要起库与服务，避免拖慢日常链）。

## 不做（范围外）

- 不测丝路港真实接口语义（无接口文档），只测「缺失/不可达」两种形态。
- 不替代各变更自己的单元/集成测试，只做**跨变更的总闸**。
- 不引入新的外部依赖（数据库复用测试库，链用本地形态或 mock sidecar）。

## Impact

- 代码：`apps/api/test-e2e/`（或既有 e2e 目录）+ `scripts/` 启动脚本；`package.json` 新 script。
- CI：可选独立 job；不配置时本地可手动跑。
- 风险：e2e 起服务较慢，控制在 2–3 分钟内；数据库用一次性 schema，跑完销毁。

## 验收

- [ ] A 形态：主链路用例全绿，互认端点返回 503 且错误信息指明确切原因
- [ ] B 形态：互认端点超时，长轮询耗时不超过基线 + 1s
- [ ] 六条契约断言各有一条对应用例，失败信息能指向具体变更
- [ ] `pnpm test:e2e:no-external` 在干净环境一次跑通（含数据库初始化）
- [ ] 文档：`docs/NDI-TR-2025-连接器与平台标准差距.md` §6 增加「总闸已跑」勾选项
