# 任务 3.2 对拍：`rws.causal-psm`

夹具：同一层、处理组 8 例结局 + 4 例无结局，对照组 4 例结局 + 12 例无结局，行按这个顺序排列。`minCell = 1`。效应量用 Q16.16 整数，再除以 65536 与浮点公式比。

## PSM

层内按输入顺序 1:1 配对（协变量在层内相同，配对就是先出现的对照）。配对差的均值是 4/12，样本标准误是 `sqrt(2/99)`。

定点模块与 `causalAteQ16` 逐字段相等。换算后的 ATE、标准误与上面两个浮点数相差都小于 0.001。

这和旧通道 `estimate_psm` 在**协变量不变化**时是同一条配对规则：特征距离全是 0，`min()` 取输入顺序里的第一个未用对照，标准误是配对差的样本标准差除以配对数的平方根。协变量分层之后，新路径**不跨层配对**；旧路径仍按年龄带序号和性别的欧氏距离跨层就近配对。那是两条估计，不能当成同一个数。

## IPTW

同一夹具上，饱和标准化的风险差是 `8/12 - 4/16`，标准误是 `sqrt((8/12)*(4/12)/12 + (4/16)*(12/16)/16)`。定点结果与 `causalAteQ16` 逐字段相等，与这个闭式相差小于 0.001。

旧通道的 IPTW 是 sklearn 逻辑回归加 50 次 bootstrap，不是这个闭式。出域数字以定点闭式为准。

## 出域与合并

节点载荷只有 `analysisType`、`cohortSize`、`method`、`suppressed`，未抑制时再加 `effectEstimate.beta` 与 `standardError`。没有个体行，也没有逐人倾向评分。

层内处理组或对照组人数（IPTW）或配对数（PSM）低于 `minCell` 的层不进入效应量。整站给不出标准误时 `suppressed = true`，平台不把 0 送进合并。两站及以上的效应量与 `derSimonianLaird` 的合并值、标准误、置信区间、异质性逐字段相同。
