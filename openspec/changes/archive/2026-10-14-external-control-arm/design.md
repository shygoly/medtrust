## Context

- 算子框架与既有场景同工艺：AssemblyScript Wasm、纯数字列 ABI、零能力（只导入 env.memory）、
  可复现构建（同源码+同编译器→同字节→同 SM3）、TS 参考模型同夹具对拍。
- 乐城叙事：单臂试验 + 真实世界外部对照是 RWD 支持注册的典型路径（见 docs/lecheng-rwe-demo-plan.md D1）。

## Goals / Non-Goals

**Goals:** 节点内确定性窗口匹配（可复现、可对拍）；逐层六格计数 + 宿主侧 RR/RD；不可估语义；与答案键逐格对拍。
**Non-Goals:** 倾向评分/IPTW 等依赖协变量向量的匹配（本期只做「层 + 索引日窗口」确定性匹配）；
多臂/剂量反应；协变量连续值平衡（本期不进投影）。

## 决策

### D1 匹配语义（确定性，无暂存）
两侧按（分层, 索引日, subjectKey）排序；对每个受试者（按日升序）：
① 丢弃「日 < 受试者日 − caliper」的对照（单调指针，后续受试者日只会更晚）；
② 窗口内**从最早起**取至多 ratioK 个；③ 取到 ≥1 即匹配并消耗所取对照，否则未匹配。
「窗口内取最早」使模块不需要任何暂存区标记已用——排序 + 单调指针即可，语义仍确定。

### D2 排序决胜依赖 subjectKey（本变更执行中发现并修掉的坑）
同日并列对照的取舍顺序由排序决胜（subjectKey）决定；封存投影会把院内假名改写为 linkKey，
因此**答案键/任何参考计算 MUST 按投影后形状（subjectKey := linkKey）计算**，否则贪心会取到不同对照
（首次对拍即失败并暴露）。此问题已固化进生成器与对拍。

### D3 ABI 与返回码
头 16B `[nTrial][nCtrl][caliperDays][ratioK]`；两侧各三列（day i32 / outcome u8 / stratum u8）；
输出 k×6 u32。返回 0 成功 / 3 分层越界 / 5 参数非法 / **6 排序契约破坏**（镜像 dedup-incidence）。

### D4 不变量与不可估
宿主侧三条不变量（见 proposal）；估计层 matched=0、对照=0、任一侧零事件 → null（「不可估计」），
与 VE 的 vaccPos=0 口径一致。发布审查桶取 min(matched, 对照数) 按 minCell 判。

## Risks / Trade-offs

- 确定性「窗口内取最早」不如最优匹配（最近邻/倾向评分）平衡好——如实标注，后续可加协变量分箱匹配算子。
- 试验与对照的索引日语义（入组日 vs 诊断日）由数据方保证；投影只验形状不验临床语义。
