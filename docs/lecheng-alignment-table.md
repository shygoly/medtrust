# 乐城指南条款 ↔ 本方案能力对照表（P0 口径对齐）

> 依据原文：《乐城先行区临床真实世界数据用于支持进口药品和医疗器械注册申报工作指南（试行）》
> 海南省药品监督管理局 2026-04-29 印发（[原文链接](https://amr.hainan.gov.cn/himpa/xxgk/tzgg/202604/t20260430_4068577.html)，2026-10 检索）。
> 本表把指南的**真实条款**映射到本仓能力与证据，供与真研院/审评机构沟通时对齐术语。
> **如实声明**：本仓演示全部基于合成数据；映射证明的是「范式与链路」，不构成任何申报材料。

## 六、如实差距清单（对真研院沟通时主动讲清）

1. **协变量平衡与倾向性评分未做**（指南对照合理性的进阶要求）——本期确定性匹配只做「层 + 索引日窗口」；
2. **源数据核查（SDV）不在本方案范围**（属医院侧流程，指南要求申请人自查）；
3. **伦理与受试者保护流程未建**（指南 §四（五）全节）——真实数据接入前提（本仓 REG-08 闸门）；
4. 演示为合成数据——**不构成申报材料**，映射证明的是范式与链路的契合度。
