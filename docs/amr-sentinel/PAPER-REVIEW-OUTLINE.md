## 0. 摘要（草稿）

**背景**：区域抗菌药物耐药（AMR）监测与真实世界研究（RWS）需要多中心数据，但面临数据不出域、折点体系不一致、罕见表型小单元格重识别三类约束。  

**目的**：综述隐私计算与联邦分析在耐药监测中的进展，提出以**可信数据空间**为载体的分析阶梯（描述 → 信号 → 因果 → 算法验证），并以可复现合成 AST 验证关键控制点。  

**方法**：文献综合（含目标试验模拟、折点协调、抗感染因果定向语料）；双连接器联邦编排；输出闸门（minCell）与数字契约强制执行。主评价数据为 **CHINET-prior synthetic AST**（非 Synthea，非真实院内行级数据）。  

**主要发现（已验证部分）**：联邦 Q1 可将双院聚合耐药率合并且对齐 CHINET 带宽；Q2 实证「单院小细胞压制、联邦报告仍可发布」的闸门行为。折点重判读敏感性（实验 C）与因果注入效应回收（实验 D）按路线图推进。  

**局限**：合成评价不能外推真实疗效或真实耐药负担；真实双院接入前结论止于方法与系统。  

**关键词**：抗菌药物耐药；可信数据空间；联邦真实世界研究；小细胞抑制；折点对齐；目标试验模拟；合成数据

## 1. 引言

### 1.1 耐药危机与区域监测需求

中国及全球 AMR 负担持续上升，国家级哨点（如 CHINET、CARSS）提供聚合基线，但**区域多医院、准实时、可分层**的监测与研究仍受数据共享制度与技术架构限制。感控与临床药学需要的不仅是年报级 R%，还包括稀有表型可见性、用药–耐药信号，以及审慎的因果问题（经验方案与结局）。

### 1.2 多中心研究的三类瓶颈

| 瓶颈 | 表现 | 本文对应控制 |
|---|---|---|
| 共享壁垒 | 原始药敏/病历不出域 | 连接器本地计算，仅聚合出域 |
| 方法学异质性 | CLSI vs EUCAST、版本、编码 | 折点对齐契约 + 重判读（P0） |
| 隐私重识别 | 小分层、罕见菌耐药格 | OutputGate minCell；行级禁出 |

### 1.3 范围与非目标

- **覆盖**：监测描述、用药–耐药信号、抗感染 RWS 因果规格、算法外验证的联邦形态。  
- **不覆盖**：替代治疗指南的个体处方决策终审；以基因组 WGS 为主叙事的预测竞赛。  
- **数据**：§数据声明；主文不使用 Synthea 作为 AMR 证据。

### 1.4 贡献（与提案差异化对齐）

1. **小细胞抑制的反转叙事**：把输出闸门从「结果缺失」转为可检验的联邦监测特性（Q2）。  
2. **折点对齐作为一等公民**：跨院可比性依赖显式、可机器校验的折点契约（P0 / 实验 C）。  
3. **描述→因果的联邦阶梯**：在可信数据空间上复用 RWS 阶梯，而非「又一个中心化耐药预测模型」。

## 2. 相关工作综述

### 2.1 传统多中心耐药监测网络

WHONET、医院感染监测网与国家级年报构成当前主流：优势是标准化导出与长期基线；短板是中心化汇聚假设、折点版本漂移常被低估、以及行级共享在伦理与法务上日益困难。本文关注**在不出域约束下仍可完成同等分析阶梯**的架构。

### 2.2 隐私计算与联邦学习在医疗中的应用

联邦学习（FL）、安全多方计算（MPC）、可信执行环境（TEE）已在影像、预后模型等场景验证。AMR 监测更依赖**聚合计数与效应量**，而非参数平均；因此**出域闸门、合约用途绑定、审计存证**与 FL 同等重要。本平台一期小细胞控制以阈值抑制为主（非 ε-DP 账本）。

### 2.3 真实世界证据与目标试验模拟在抗感染中的应用

抗感染因果易受适应证混淆、时间零点与竞争风险影响。目标试验模拟（TTE）为观察性数据提供可辩护规格（纳入排除、grace、washout、结局定义）。定向语料见 `data/raw/pubmed-targeted/q4-tte-methods` 与 `q4-clinical-benchmark`（检索式固化于 `scripts/amr/fetch_pubmed.py`）。

### 2.4 合成健康数据在方法学评价中的角色

**Synthea** 等通用 EHR 合成器广泛用于卫生信息学与隐私系统论文，适合流程与互操作验证，**不内建中国哨点耐药边际或 EUCAST 折点约束**。因此 AMR 方法学评价需要 **领域先验合成**（CHINET 边际 + 折点一致 MIC），否则「联邦跑通」与「耐药结论可信」会假性绑定。  
**发文边界**：合成数据可支撑方法/系统/隐私赛道；不可支撑真实流行病学断言（见 §数据声明）。

### 2.5 研究空白

同时将 **出域闸门、折点契约、联邦 RWS 阶梯** 工程化并在 AMR 场景可复现验证的工作仍少。既有联邦医疗工作多优化模型性能，较少处理哨点监测的折点敏感性与小细胞发布逻辑。

## 3. 概念框架：可信数据空间上的 AMR 分析阶梯

### 3.1 双平面

- **控制平面**：参与方身份、数字契约、任务编排、聚合合并与存证。  
- **连接器平面**：本地药敏/病历、去标识、TEE 内分析、OutputGate；**原始行级永不跨域**。

### 3.2 数字契约与用途绑定

约束四元组：`purpose` / `retention` / `output` / `validUntil`；结构化 `outputPolicy`（preset、allowedArtifacts、minCell）。PEP 在计算前校验；闸门消费合约 minCell（下限与 DOMAIN 中 `DEFAULT_MIN_CELL=5` 对齐）。

### 3.3 输出闸门（对应 Q2）

对聚合桶：`0 < count < minCell` → `count=0` 且 `suppressed=true`；行级/直接标识直接拒绝。当前联邦合并为 **gate-then-merge**：各院先过闸再求和。

### 3.4 折点对齐契约（对应差异化 #2）

院方上报元数据：`breakpoint_system`、`breakpoint_version`；研究侧以 EUCAST 公开表为可复现统一重判读基准，保留原判读作敏感性分析（CLSI 全文不二次分发）。

### 3.5 阶梯 Q1–Q5 与证据等级

| 编号 | 临床问题 | 阶梯 | 分析类型 | 证据角色 |
|---|---|---|---|---|
| Q1 | 主要致病菌耐药率与分层 | L1 | `condition-prevalence` | 描述 |
| Q2 | 罕见表型单院压制 / 联邦可见 | L1 | 患病率桶 + 闸门 | 隐私×监测 |
| Q3 | AUD 与耐药信号 | L2 | `disproportionality` | 信号（非因果） |
| Q4 | 经验方案 → 30 天死亡 | L3 | `causal-psm` / `causal-survival` | 因果（规格锁定） |
| Q5 | 算法外验证与迁移 | L4 | `algorithm-validation` | 算法性能 |

工程续做顺序见 [`SCENARIO-ROADMAP.md`](./SCENARIO-ROADMAP.md)：P0 折点 → P1 Q4 → P1′ Q3。

## 4. 方法学要点深述（综述核心章）

### 4.1 耐药率与分层报告规范

首分离株 / 标本类型去重、ICU 与非 ICU 分层、分子分母定义透明。合成评价中以 CHINET 边际对齐作为**生成质量门**（非真实率估计）。报告时区分「模拟株耐药标签患病率」与「哨点真实率」。

### 4.2 小细胞与差分隐私

阈值抑制（minCell）实现简单、可审计，但 **gate-then-merge** 下双侧皆低于阈值会导致合并后信号消失。ε-DP 账本为本平台后续项（TRUST P-CTL-3）。论文讨论须诚实表述当前语义。

### 4.3 CLSI / EUCAST 差异与敏感性分析设计

同一 MIC 可映射不同 S/I/R；I 类语义在 EUCAST 2019 后亦有变化。设计：固定 MIC 网格，分别套 native 与 EUCAST 阈值，计算 ΔR%（百分点）。语料：`breakpoint-harmonization` 定向库。**此节决定论文是否超出「又一个联邦 demo」**（实验 C）。

### 4.4 用药–耐药信号

DDDs/100 人天与耐药检出的 ROR/PRR 适用于假设生成；混杂、适应证与多重检验导致假阳性。合成或真实医嘱缺失时不得宣称「证实因果」。效力不足时保留 warning 而非静默。

### 4.5 抗感染因果：TTE 要素

- 时间零点：如首次阳性血培养采样日  
- 暴露/对照：碳青霉烯经验治疗 vs β-内酰胺酶抑制剂复方  
- grace / washout、纳入排除、30 天全因死亡与行政删失  
- 匹配协变量：年龄段、性别、基线 ICU、合并症、标本、既往抗菌暴露等  

合成层通过 `q4_effect.yaml` **注入**效应（`bli_noninferior` / `merino_superior`），评价流水线是否回收，而非估计真实 HR。

### 4.6 算法外部验证

跨站点 AUC/校准与异质性；联邦协议禁止行级汇聚。Q5 定位为「迁移性与闸门下的验证」，避免与中心化刷分模型竞赛。

## 5. 可复现系统验证（Results；合成）

> 本节全部基于 **CHINET-prior synthetic AST**。样本规模默认每院 5 000 分离株级连接器切片（以本地 `data/synthetic/amr/connectors/` 为准；该目录 gitignore，需按脚本再生）。

### 5.1 数据生成

- 先验：CHINET 聚合耐药率；MIC 两倍稀释网格 + EUCAST v16.1 标签。  
- 双院异质性：菌种倾斜、ICU 率、罕见表型 boost（示范甲压低 / 示范乙抬高，服务 Q2）。  
- Q4：`--with-t1` 生成感染事件与暴露/结局；效应预设版本化于 `scripts/amr/priors/q4_effect.yaml`。  
- **非 Synthea**。

### 5.2 实验 A：联邦 Q1 耐药率 vs CHINET 带宽

- **设置**：示范甲 + 示范乙加载 `records.json`；药企目的「抗菌药物耐药监测真实世界研究」；`condition-prevalence`；仅聚合出域。  
- **命令**：`pnpm --filter @medtrust/connector demo:amr-q1`  
- **已观察结果（示例运行）**：合并队列 n=10 000；关键组合如 kpn/MEM R% 落在与 CHINET 对照的合理带宽（演示硬门：约 10%–40%）；行级 `exportRaw` 外部调用拒绝；结果 JSON 不含 `subjectKey`。  
- **解释**：证明联邦描述层可跑通且边际可控；**不**声称该 R% 为两家真实医院率。

### 5.3 实验 B：Q2 小细胞反转

- **设置**：同契约；关注桶 `rare_colistin_r_aba`；`minCell=5`。  
- **命令**：`pnpm --filter @medtrust/connector demo:amr-q2`  
- **已观察结果（示例运行）**：

| 侧 | 闸门前 raw | 过闸后 | 含义 |
|---|---|---|---|
| 示范甲 | 3 | count=0，`suppressed=true` | 单院压制 |
| 示范乙 | 76 | count=76，可发 | 对侧可单独出域 |
| 联邦合并 | — | count=76 | 联邦报告可发（压制侧贡献已清零） |

- **解释**：实证 OutputGate 真实行为与「单院压制、联邦语境下表型仍可发布」叙事；当前为非对称设计，与 **gate-then-merge** 一致。更强「双院皆压再解锁」见路线图 P2。

### 5.4 实验 C（规划）：折点重判读前后 ΔR%

- **状态**：待 [`SCENARIO-ROADMAP.md`](./SCENARIO-ROADMAP.md) P0。  
- **计划指标**：≥3 个菌药组合给出 native vs EUCAST 的 Δpp；联邦合并表双列对照。  
- **数据**：仍为合成 MIC；可复现、可开源（EUCAST 公开）。

### 5.5 实验 D（规划）：Q4 注入效应回收

- **状态**：待路线图 P1；`demo:amr-q4`。  
- **计划指标**：在 `bli_noninferior` 与 `merino_superior` 下，回收的 HR/ATE 落入预设带；与 `q4-clinical-benchmark` 文献效应量带对照时仅作**量级讨论**。  
- **红线**：不写临床优效/非劣结论。

### 5.6 安全性质

- 外部 origin 行级导出失败（Q1/Q2 演示）。

- 无生效契约则不分派。  
- 聚合载荷无患者直接标识字段。

## 6. 讨论

### 6.1 与「中心化汇总后再分析」的对比

中心化路径假设行级或宽表可汇聚，分析灵活但触碰共享与合规天花板。联邦路径牺牲部分探索自由度（制品白名单、闸门），换取可审计的出域边界。AMR 监测的主流产物本就是聚合率与效应量，与该权衡匹配。

### 6.2 合成评价的外推边界（回应「假数据有何用」）

合成研究用于：(1) 证明控制点与流水线在对抗性设定下行为正确（如小细胞、注入效应）；(2) 在公开折点与先验下提供**可复现基准**；(3) 在真实数据到达前降低集成风险。  
**不能**替代真实人群推断。Synthea 类通用合成器亦同理，且更不适合 AMR 主表——故本文采用 CHINET-prior 合成并显式排除 Synthea 主结果。

### 6.3 伦理与合规

最小必要、用途绑定、阅后即焚、审计链与国密哈希存证，与个保法及行业使用控制要求同向。小细胞抑制是降低重识别风险的工程控制，不是对罕见病原「视而不见」的科学借口——联邦合并与样本量设计应一并讨论。

### 6.4 对感控实践的含义

- **区域耐药看板**：Q1/Q2 级产物在闸门下可发布时，可支撑院感沟通。  
- **个体经验治疗建议**：证据门槛更高，需因果规格、校准与人在回路；Advisor 宜后置。  
- **折点不统一**：任何跨院对比若不做重判读，感控解读可能被方法学噪声主导。

### 6.5 局限与下一步

- 合成 AST；无真实双院行级验证。  
- gate-then-merge 限制双侧小细胞解锁叙事。  
- 无 ε-DP 账本；软件 TEE 标注不可虚标为硬件远程证明。  
- 下一步：P0 实验 C → P1 实验 D → 真实医院外验证。

---

## 7. 结论

在数据不出域约束下，可信数据空间可将 AMR 监测从描述推进到信号与因果规格化分析；方法学贡献应落在 **出域闸门、折点对齐与联邦阶梯**，而非单一预测模型的性能竞赛。基于 CHINET 先验的合成 AST 足以支撑可复现系统验证与方法学论文，但**不能**单独支撑真实流行病学或疗效结论；Synthea 不应用于 AMR 主结果。
