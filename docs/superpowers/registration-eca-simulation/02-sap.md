# Simulated Statistical Analysis Plan

> **SIMULATION ONLY.** This SAP is frozen only for the fictional `REG-ECA-001` exercise.

## 1. Estimand

**Population:** eligible trial population at time zero.

**Treatment conditions:** `SIM-MAB-01` plus standard care versus the external standard-care
strategy.

**Endpoint:** week-24 binary response.

**Intercurrent events:** treatment-policy strategy; rescue therapy remains in the strategy;
death/competing risk is retained and reported.

**Population-level summary:** ATT risk ratio with risk difference as a secondary summary.

## 2. Analysis populations

| Population | Definition |
|---|---|
| Source cohort | Eligible records after source-specific exclusions |
| Trial analysis set | Trial records eligible at time zero with complete strategy/outcome |
| External analysis set | Primary and optional secondary controls satisfying the frozen eligibility |
| Overlap-trimmed ATT set | Records with propensity score in `[0.05, 0.95]` |

The primary analysis uses trial and primary external control. The secondary external source
is analyzed separately for reproducibility and heterogeneity; it is not pooled into the
primary estimate.

## 3. Treatment variable and propensity model

Treatment is `trial participation = 1` and `external control = 0`.

The pre-specified logistic model includes:

```text
trial ~ age + sex + calendarYear + severity + diseaseDuration
        + comorbidityIndex + priorTreatment + keyBiomarker
```

Continuous variables are standardized. No outcome-derived variable may enter the model.

## 4. IPTW-ATT

For trial participants:

```text
weight = 1
```

For external controls:

```text
weight = e(x) / (1 - e(x))
```

Weights are trimmed by excluding propensity scores outside `[0.05, 0.95]`.

Fail-closed thresholds:

- more than 10% trimmed: stop and report overlap failure;
- maximum weight greater than 20: stop;
- P99 weight greater than 10: stop;
- effective sample size below the configured minimum: stop;
- no participants in either arm after trimming: stop.

## 5. Effect estimation

Weighted response risk in the trial arm and weighted control-arm risk are calculated.

```text
RR = p_trial / p_control
RD = p_trial - p_control
```

The primary summary is RR. A 95% interval is generated by the registered WASM kernel and
independently replicated by the Python reference implementation.

## 6. Missing data

The primary reference fixture is complete for core covariates. Missingness scenarios are
generated separately under MCAR, MAR and MNAR labels.

For the current simulation engine:

- missing core numeric cells are explicitly counted;
- deterministic mean imputation is used only inside the simulation;
- more than 20% missingness causes fail-closed termination;
- the mode and imputed cell count are published in C3 diagnostics;
- complete-case and alternative imputation are required before any real-study use.

The current deterministic rule is not represented as registration-grade multiple
imputation.

## 7. Balance and positivity

Report for every covariate:

- absolute SMD before weighting;
- absolute SMD after weighting;
- flags for post-weight SMD greater than 0.1.

Report propensity-score minimum/maximum, trimmed count and effective sample size.

## 8. Censoring and competing risk

Report:

- observed outcome count;
- censored count;
- competing-risk event count;
- follow-up distribution.

No censored participant may be silently converted to a non-event.

## 9. Sensitivity analyses

The simulation performs at minimum:

1. tighter overlap trimming;
2. alternative time-zero window;
3. alternative propensity model/covariate specification;
4. coarsened exact matching where feasible;
5. negative-control outcome;
6. quantitative bias analysis.

The result report must state direction, interval and whether the conclusion is stable.

## 10. Synthetic truth recovery

The reference scenario injects:

```text
RR_true = 0.65
control response risk = 0.35
trial response risk = 0.2275
```

A method passes only when:

- the adjusted estimate is closer to the injected truth than the crude estimate;
- the estimate lies within the pre-declared synthetic recovery range;
- residual weighted SMD is generally below 0.1;
- an unadjusted analysis demonstrates measurable confounding;
- the no-effect and missing/censoring negatives behave as predicted.

## 11. Analysis freeze

The following are frozen before outcome inspection:

- eligibility;
- time zero;
- treatment strategies;
- estimand;
- outcome phenotype;
- covariates;
- propensity model;
- trimming;
- effect measure;
- sensitivity list;
- fail-closed thresholds.

Any post-unblinding change requires a timestamped amendment and must not overwrite the
original SAP version.
