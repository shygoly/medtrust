# 药物注册场景现场演示脚本（P3 · 约 15 分钟）

> 面向：真研院 / 落地乐城的药械企业 / 医院联盟。
> 素材：`MedTrust-药物注册研究的可信空间解决方案.pptx`（18 页）+ 三条可现场复跑的命令 + 真机截图。
> 口径红线：全程合成数据；演示 ≠ 申报；不说「数据不出院」（说明文不出院）。

## 0. 开场（2 分钟 · PPT p1–p4）

- p1 一句话：「让真实世界数据走进注册申报——四类注册研究场景，在 Intel TDX 可信空间内完成患者级链接与受控分析。」
- p2 趋势：首个 RWD 支持注册品种（2020 青光眼引流管）→ 560 种国际药械落地 → 半年 6 款 → 试点申报 +292%——瓶颈从「有没有数据」变成「数据可不可信」。
- p3 审评要什么（真实性/可溯源/受控使用）→ 技术能力对照。
- p4 三堵墙（对照臂/多中心/溯源）→ 一句话方案（上了锁的计算房间）。
- 话术锚点：「监管问的从来不是数据多不多，而是数据怎么来的、能不能查。」

## 1. 方案与 Intel 底座（2 分钟 · p5 + p16）

- p5：TDX 房间（加密内存、硬件证明、密钥按证明释放）+ 至强 6 AI 解读（人复核）。
- 遇到「密文出了院安全吗」→ 用 p5 后的保障页四层回答（最小投影/密钥分持/证明后释放/算完即毁）。
- p16（附录 C）放最后答疑用：TDX Quote 原理五步。

## 2. 现场执行（5 分钟 · 终端实跑，这是可信度的核心）

> 提前备好两个终端窗口；命令都在仓库根目录。

**窗口 A：算子可信（30 秒）**
```bash
pnpm --filter @medtrust/wasm-algorithms build      # 可复现构建：975B · SM3 391914b7…
pnpm --filter @medtrust/wasm-algorithms test       # 96 项全绿（对拍 7 项 + 数据集 3/3）
```
讲法：「同一份源码、同一编译器，永远得到同一串字节和国密摘要——这就是『分析程序可验证』，被信任的代码不到 1KB。」

**窗口 B：真实运行（3 分钟）**
```bash
pnpm --filter @medtrust/connector demo:rws-scenarios
```
滚动到「③ 单臂试验真实世界外部对照」，边看边讲：
- 「单臂 460 例 × 医院对照池 5600 例，两边数据加密进房、房内逐人匹配」；
- 指着结果读数：「注入 RR=0.55 的三层还原 0.52 / 0.52 / 0.58，置信区间都不含 1；负例层 1.15，区间覆盖 1——**该不显著就不显著，这是我们如实呈现的设计行为**」；
- 收尾指「与答案键逐格一致 ✓」：「每一格都能对上事先算好的真值。」

**衔接真机（1 分钟 · PPT p10）**：切到真机截图页——「同样的模块字节在 Intel TDX 客户机内实测过，现场有真实的硬件 Quote（5006 字节）与逐格一致的结论；三台 Intel 主机按需开机、跑完即停。」

## 3. 四场景与治理（4 分钟 · p6–p9、p11）

- p6 D1 外部对照（乐城主线，§二（二）2 的直接对应）；
- p7 D2 罕见病登记（一人不算两遍；直接相加虚增 ≈20% 人头 / 25–33% 罕见病）；
- p8 D3 安全监测（附条件批准后的安全网，真机全链路）；
- p9 D4 国际多中心（数据不出境、密钥境内——对应乐城指南「RWD 原则上不跨境」）；
- p11 FAIR + 5-Safes：「受控不等于不开放——英国把受控环境分析做成了制度。」
