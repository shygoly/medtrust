## 1. 定位一句话

乐城的核心诉求是「**真实世界数据能不能支撑注册申报**」——即数据的真实性、完整性、可溯源与受控使用（指南原文要义）。本计划用可信空间（Intel TDX 节点）把 A 类四场景做成**可复核的注册研究范式演示**：每一份演示产物都自带证据包（答案键、回执链、模块摘要、真机实测记录），对应审评最关心的「可溯源」。

## 3. D1 技术设计（计划的核心新增）

- **算子** `rws.external-control@1`：复制 `ve-tnd` 的全部工艺（纯数字 ABI、零导入、排序契约、返回码语义）。
  - 输入：试验组表（层、入组日、结局日或 0）+ 对照候选池表（层、诊断日、结局），均按（层,主体,日）排序；
  - 节点内：同层确定性 1:k 匹配（|入组日−诊断日| ≤ caliperDays 贪心匹配）；
  - 输出：每层 matched / expPos / expNeg / ctlPos / ctlNeg / unmatchedExp；
  - 宿主侧：RR、RD + Woolf CI、协变量平衡（分箱近似 SMD）、minCell 抑制。
- **数据** `build-external-control-records.mjs`：Synthea 基座产「医院历史对照池」（n≈5000）+ 注入「单臂试验人群」（n≈200，效应 HR≈0.65）+ 答案键（期望匹配数与逐层 2×2）。
- **验收**：对拍 ≥8 项（含卡尺边界、无匹配层、排序违约）+ TDX 客户机实测逐格一致 + 证据包 + 截图。

## 5. 治理映射（对齐审评话语）

- **FAIR**（`docs/rws-trusted-space-solution.md` §1）：I 强（OMOP CDM + 术语白名单）、R 强（方法可复用：同字节算子 + 答案键）；P2 补 F 的数据卡与 A 的接口映射说明。
- **5-Safes**：safe people（合约主体+证书）· safe projects（合约用途）· safe settings（**TEE+硬件证明**）· safe data（最小投影+假名）· safe outputs（**双阈值发布审查**）。
- **乐城指南要素对照**：真实性/完整性 → OMOP CDM + 逐记录溯源 + 答案键；可溯源 → 回执链上链 + 独立离线核验；受控使用 → 合约 + PEP + TEE。

## 6. 边界（如实）

1. 全部合成数据、注入真值——演示验证的是**范式与链路**，不是任何品种的疗效/安全性；
2. 不构成注册申报材料；真实申报需真实数据 + 伦理与合规审批（REG-08）；
3. D4 为沙盘演示（数据流与密钥境内控制），不涉及真实跨境传输。
