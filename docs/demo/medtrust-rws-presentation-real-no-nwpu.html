📋 L1.5 · 方案简介

失衡信号检测

看某个药是不是和某种不良反应“异常地”经常一起出现

🧭 一句话说清

在很多医院的真实病历里，快速找出「某个药是不是和某种不良反应，异常地经常一起出现」。一起出现得离谱，就是一个值得警惕的“信号”。

💡 为什么要做（对药企的价值）

药品上市后，真实使用中可能冒出临床试验没发现的副作用。这个分析帮药企在海量真实病历里「尽早发现苗头」，为修改说明书、上报监管、做风险管理提供第一手线索——比等各地个案报告一点点堆起来，要快得多。

🔬 一次分析是怎么跑的

  1. 消费方在目录申请/绑定合约后，发起 RWS 任务（可多选华山+瑞金两份生效合约）
  2. 控制面校验合约目的一致且 active —— 否则拒绝，碰不到数据
  3. 各院 worker 出站拉取任务，PEP 校验后在本院本地执行
  4. 院内统计四格表 / 效应量等，输出闸门按 minCell 过滤
  5. 只回传聚合摘要（不是病人名单）；阅后即焚策略约束留存
  6. 控制面合并两院结果，形成可审计的证据链

🔒 “数据不出域”是怎么做到的

病历始终锁在医院里。系统的做法像「把计算题送进保险箱，只取回答案」：跨出医院的只有「多少人」这样的汇总数字，绝不含任何一条病人记录。既查出了信号，又没让原始数据离开医院，符合《数据安全法》。

📖 名词解释（大白话）

  • 信号：某个『药—不良反应』组合异常扎堆出现；扎堆得离谱就值得警惕
  • 失衡分析（PRR/ROR）：两个用来算『扎堆程度』的公式，数值越大越可疑
  • 四格表：把人按『用没用药』和『有没有出事』分四类各数多少，是算信号的原料
  • 队列：这次纳入分析的病人总数（本次两院合计 290 人）

📋 L2 · 方案简介

比较效果分析

把多家医院的真实疗效结果，科学地合并成一个结论

🧭 一句话说清

把好几家医院的真实疗效结果，科学地「合并」成一个更有说服力的结论——A 药到底比 B 药（或标准治疗）好多少。

💡 为什么要做（对药企的价值）

临床试验环境很理想化，真实世界里病人更复杂。药企和医保想知道药在「日常诊疗」下真实好多少。多院结果一合并，样本更大、更可信，是医保准入、进院谈判的关键证据。

🔬 一次分析是怎么跑的

  1. 药企提交任务：比哪两组、看什么结局、要不要按年龄性别分组
  2. 「数字合约」校验通过后分发到各院
  3. 每家医院在本地算出「效应量」（好多少）和它的「误差范围」
  4. 只把这两个数字回传出来
  5. 中心按各院结果的可靠程度加权，合成一个总结论，并画出「森林图」、检查各院是否一致

🔒 “数据不出域”是怎么做到的

同样，病人数据不出院。跨域流动的只有「效应量＋误差范围」这类统计摘要。中心拿这些摘要就能合并出总体结论，不需要看任何一条原始病历。

📖 名词解释（大白话）

  • 效应量：一个药比另一个好（或差）多少的数值
  • 误差范围 / 标准误：这个数值有多靠谱，范围越窄越可信
  • 合并（Meta 分析）：把多家医院结果科学地『加权平均』，更可靠的院权重更大
  • 森林图：把各院结果和合并结果画在一起的图，一眼看出一致不一致
  • 异质性 / I²：各院结果彼此差多少；I²=0% 表示高度一致

📋 L3 · 方案简介

因果推断分析

排除干扰，搞清楚到底是不是药本身更好

🧭 一句话说清

排除干扰因素，尽量搞清楚「是这个药真的更好，还是只是用这个药的人本来就更健康」。

💡 为什么要做（对药企的价值）

真实世界里，医生给谁开哪种药不是随机的（比如年轻人更可能用某种药），这会造成假象。这个分析用「配对」把两组病人的背景拉齐再比，得到更接近因果的结论。在没法做随机对照试验时，这是药企拿到高质量证据的关键手段。

🔬 一次分析是怎么跑的

  1. 药企提交任务：暴露组 vs 对照组（如 ACEI vs ARB）、关心的结局、随访规则
  2. 「数字合约」校验后分发到各院
  3. 每家医院在本地做「倾向评分匹配」：给每个用 A 药的人，找一个背景相似但用 B 药的人配成一对，把两组拉齐
  4. 在配平后的人群里算出效果和误差，只回传这两个数字
  5. 中心合并，得到带可信范围的总体效应

🔒 “数据不出域”是怎么做到的

配对、以及「背景是否拉齐」的检验，全部在院内完成，外面看不到任何病人明细。跨出去的只有「配平后的效果＋误差」，原始随访记录一步都没出院。

📖 名词解释（大白话）

  • 混杂：干扰因素，让『看起来 A 更好』其实可能是别的原因造成的
  • 倾向评分匹配（PSM）：给两组病人『背景配对拉齐』的方法，尽量排除混杂
  • 效应（ATE / β）：背景拉齐之后，A 相对 B 的真实效果大小
  • 风险比（Cox）：分析『多久会发生某个结局』；风险比小于 1 表示风险更低
  • 置信区间：结果的可信范围，不跨 0（或 1）通常表示『显著』

📋 L4 · 方案简介

联邦学习预测

几家医院联手训练模型，数据谁也不给谁看

🧭 一句话说清

几家医院「联手」训练一个预测模型（比如预测病人将来会不会肾衰竭），但数据谁也不给谁看。

💡 为什么要做（对药企的价值）

好模型需要大量数据，可医院之间不能互传病历。「联邦学习」让各院用自己的数据在本地训练，只交换「学习心得」（不是数据），最后拼成一个更强的模型。药企拿到的是能用的预测模型，用于患者分层、风险预测，甚至多家药企联合研发，而谁都没泄露数据。

🔬 一次分析是怎么跑的

  1. 药企提交任务：用哪些指标、预测什么、隐私强度设多少
  2. 「数字合约」校验后分发到各院
  3. 每家医院用本地数据训练，产出的是加密后的「学习增量」（不是数据）
  4. 系统安全地把各院增量合并，并掺入「隐私噪声」防止反推个人
  5. 反复几轮得到最终模型，输出准确度（AUC）等指标并上链存证

🔒 “数据不出域”是怎么做到的

原始数据、以及中间的「学习增量」都是加密的，跨域只走加密后的模型增量。再叠加「差分隐私」（往结果里掺一点噪声）和「最小人数保护」（人太少就不出结果），既训练出可用模型，又无法反推任何一个病人。

📖 名词解释（大白话）

  • 联邦学习：多家机构『各自在家做题、只交思路』，合起来训练一个模型，数据不出门
  • 学习增量 / 梯度：模型每一步『学到的调整量』，是一串数字，不是病历
  • 安全聚合（SecureBoost）：把各院增量加密后再合并，谁也看不到别人的原始贡献
  • 差分隐私（ε）：往结果里掺一点可控的噪声，让人无法反推个体；ε 越小越隐私
  • AUC：模型区分『会不会发生』的准确度，1.0 是满分
