## 跨切面模型(说一次,各处引用)

数据空间的功能不是孤岛,以下共享模型贯穿所有域——**在各域里只引用,不重复推导**。

### X1. 一条主轴闭环
`数据产品发布(分级/确权)` → `数字合约(授权载体)` → `使用控制 PEP/PDP/PXP(强制)` → `连接器本地 TEE 执行(数据不出域)` → `输出闸门(DP/小单元格抑制/白名单塑形)` → `聚合结果出域` → `证据上链 + 按贡献分账`。
任一环节失败 = fail-closed(默认拒/不出域)。

### X2. 三平面分离(不可退化回中心化)
- **控制面**(`apps/api`,瘦):只持元数据——目录/身份/合约/存证索引/台账。**无原始数据。**
- **数据面**(连接器,重):原始脱敏数据 + 本地审计永驻本地;真实接入节点 = `apps/agent`(Fly connector-a/b),非 `apps/connector`(自包含 demo)。
- **存证面**(FISCO):只存证据哈希,不存数据(D6)。

### X3. 统一身份/信任链(国密)
SM2 证书(中心 CA 签发)+ SM2 加密 / SM3 完整性 / 签名安全信道(D8)。证书吊销/过期立即阻断任务交互。跨空间靠**信任清单**(本空间信任的其他空间 CA 集合,D11)。

### X4. 统一裁决-执行架构(对齐 IDS)
**PDP**(`secretflow-admission` 合约门 + L2 `compliance-engine` 风险门,verdict=auto/review/block)→ **PEP**(连接器拦截数据流,block 即不派发)→ **PXP**(出域后义务:上链 + 分账 + 通知)。**关键义务须在出域前完成**(D-UC-2)。

### X5. 统一贡献计量 → 分账
贡献由 orchestrator **客观计量**(`perNode.cohortSize` / agent `contributions`,drop-penalized),**禁止使用方单方声明**。`share_i = contribution_i / Σ contribution_j`,`amount_i = budget × share_i`。口径升级见 D-VS-1。

### X6. 统一原生能力复用(勿重造)
- RBAC: `ParticipantRolesGuard` + `@ParticipantRoles(...)`;角色 = provider/consumer/operator/**compliance**(新增,已端到端)。
- 审计: `AuditService`(控制面)+ `LocalAuditLog`(连接器);关键步骤摘要上链。
- 加密: `@EncryptedColumn` 列级加密、`@Masked` 响应脱敏、Vault 密钥(5min 缓存)。
- 调度/字典/健康: 复用现有,勿自建。

## Fly.io 部署现实 → 深度需求约束(本项目独有锚点)

8/8 Fly app 全真实部署,但若干能力是**真实接入 + mock 内核**,深度需求第 3/7 维必须吃下:

| 能力 | Fly 现实 | 对深度需求的硬约束 |
|---|---|---|
| 链上存证写入 | **已从 FISCO 迁移到长安链 ChainMaker**(`fly-services/chain-sdk` Java sidecar,真实 `storeAttestation` 写入);migration 阶段 0–4 已通过 | 不再是 mock。残留:sidecar 密钥/口令治理 + solo 单节点共识 → D-RWS-3-a/b(★)。详见 [04 技术选型](04-技术选型-架构级决策点.md) |
| TEE 机密计算 | 实跑 `runtime=torch` 软件 fallback(非海光 CSV,无远程证明) | 不可向医院声称硬件级机密计算;须如实标注 → D-RWS-4(★) |
| API 运行 | 必须 `NODE_ENV=development`(否则 synchronize 关→无表;Vault 连不上→崩溃);ephemeral SQLite,靠 seeder 填充 | 生产化前:控制面迁 Postgres、Vault 正式化、关 synchronize 用 migration |
| 连接器 | 真实接入节点 = `apps/agent`(connector-a/b);`apps/connector` 是不接控制面的 NestJS demo | 两套连接器需收敛 → D-CN-1(★) |
| 运行状态上报 | 未实现(NDI-TR-2025-05 必备能力) | 控制面无法感知连接器异常 → D-CN-2 |
