## 3. 生产流程

1. `cd pitch/generators && node build-drug-registration.js`（证据缺位时 D2 表退化为空并保持页结构，不编数字）；
2. `soffice --headless --convert-to pdf` + `pdftotext` 逐页关键词校验（17 页 × 关键词清单）；
3. 几何自检：表格 colW 合计 ≤ 版心 12.09；截图页图说明不与结论条重叠；
4. 闸门：`check-meta-docs` 0 error + `pnpm governance` 通过。

## 4. 验收标准

- 页数 19，逐页关键词命中（清单见 §2）；
- D1 页无任何结果数字（P1 未完成前的硬约束）；
- 口径角标四态齐全且各只出现在应出现的页；
- 截图 3 张真实嵌入（PPT media 计数 ≥3）。
