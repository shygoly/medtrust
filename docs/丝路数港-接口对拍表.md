# 丝路数港 接口对拍表（P2-2 区域节点对接）

> 状态：MedTrust 侧落地完成，待《数据基础设施接入指南》93 接口正式文档补齐字段级语义。
> 依据：`docs/丝路数港-身份对接可行性评估.md` + `docs/TC609-6-2025-16-整改计划.md`。
> 原则：丝路数港只做「主体注册 + 身份互认」，不替代本空间 SM2 CA 密码学身份（D-ID-1）；目录同步只推元数据，不推任何行级医疗数据（D1）；日志上报只推摘要/存证指针，不推原始审计明细中的敏感字段。

## 1. 身份互认（主体注册同步）

| 接口域 | 方向 | MedTrust 落地 | 实体/端点 | 状态 |
|---|---|---|---|---|
| 注册主体拉取（区域节点 → 本空间） | 拉 | 定时/手动触发同步，upsert 主体缓存并自动映射 `cp_participant` | `POST /admin/interop/silk-road/sync` → `cp_interop_subject` → `cp_participant` | ✅ 已落地（HTTP 客户端语义待接口文档） |
| 注册主体检索 | 本空间内 | 用户按 USCC 检索已同步主体，带入机构认证 | `GET /account/interop/silk-road/subjects?uscc=` | ✅ 已落地 |
| 主体带入机构认证 | 本空间内 | 预填 `OrgCertificationApplication`（source=silk-road） | `POST /account/interop/silk-road/subjects/:id/import` | ✅ 已落地 |
| 主体状态回推（本空间认证结果 → 区域节点） | 推 | 待接口文档确认字段 | `SilkRoadClient` 预留 | ⏳ 待接口文档 |
