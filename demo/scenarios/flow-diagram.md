## 技术对比表

| 特性 | 联邦学习 (FL) | 多方安全计算 (MPC) | 可信执行环境 (TEE) |
|------|--------------|-------------------|-------------------|
| **适用场景** | AI模型联合训练 | 敏感数据统计 | 复杂敏感分析 |
| **数据位置** | 本地保留 | 本地保留 | 加密上传至TEE |
| **交换内容** | 加密模型梯度 | 加密计算中间结果 | 无需交换 |
| **计算效率** | 中等 | 较低 | 高 |
| **安全级别** | 密码学安全 | 信息论安全 | 硬件级安全 |
| **精度损失** | 无 | 无 | 无 |
| **示例应用** | 疾病预测模型 | 发病率统计 | 基因分析 |
| **技术框架** | Flower, FATE | MP-SPDZ, EMP | Intel SGX, AMD SEV |
