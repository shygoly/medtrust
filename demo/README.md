# MedTrust 演示方案

> 医疗数据可信空间演示系统 - 展示多方协作、合规处理、数据流通

## 🎭 演示场景概览

### 场景设定
**背景**: 某区域医疗数据联盟，多家医疗机构和科研机构在保护患者隐私的前提下，进行联合科研和数据分析。

**核心故事线**:
1. **数据提供方**（医院）上传脱敏后的医疗数据资产
2. **数据消费方**（科研机构）申请使用数据进行研究
3. **平台**通过隐私计算技术实现"数据可用不可见"
4. **区块链**记录全流程，确保合规可追溯

## 🔬 演示分析任务（6个场景）

### 场景1: 联邦学习 - 心血管疾病预测
- **参与方**: 华山医院 + 瑞金医院 + 医科大数据研究院
- **技术**: Flower联邦学习 (横向联邦)
- **输入**: 两医院各提供5000例心血管疾病数据
- **输出**: 联合训练的风险预测模型
- **特点**: 数据不出院，模型共享

### 场景2: 多方安全计算 - 疾病发病率统计
- **参与方**: 华山医院 + 瑞金医院 + 卫健委
- **技术**: MP-SPDZ (Shamir协议)
- **输入**: 各医院加密后的患者数量
- **输出**: 区域疾病发病率（不泄露单院数据）
- **特点**: 隐私求和、隐私均值

### 场景3: 可信执行环境 - 基因数据分析
- **参与方**: 瑞金医院 + AI医疗科技公司
- **技术**: 阿里云SGX TEE
- **输入**: 加密基因数据
- **输出**: 基因突变分析报告
- **特点**: 敏感数据在可信环境中计算

### 场景4: 数据沙箱 - 药物关联分析
- **参与方**: 华山医院 + 医科大数据研究院
- **技术**: 安全沙箱环境
- **输入**: 糖尿病用药数据
- **输出**: 药物疗效关联分析
- **特点**: 结果脱敏后输出

### 场景5: 区块链存证 - 完整流程追溯
- **记录内容**:
  - 数据资产上链哈希
  - 访问申请审批记录
  - 计算任务执行日志
  - 结果交付凭证
- **展示**: 交易哈希、区块高度、时间戳

### 场景6: 数据合规审核流程
- **流程**:
  1. AI公司申请使用影像数据
  2. 平台自动合规检查
  3. 华山医院审批
  4. 卫健委敏感数据审批
  5. 计算任务执行
  6. 结果脱敏交付
  7. 全流程上链存证

## 🚀 快速开始演示

### 步骤1: 初始化演示数据
```bash
# 运行数据初始化脚本
pnpm demo:seed
```

### 步骤2: 启动演示模式
```bash
# 启动完整演示环境
pnpm demo:start
```

### 步骤3: 访问演示场景
- Landing Page: http://localhost:3000
- 管理后台: http://localhost:3000/dashboard
- API文档: http://localhost:3001/api/docs
