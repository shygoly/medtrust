# 医疗数据定价：理论体系 · 模型 · 可算公式

> 面向场景：**医疗健康数据要素的定价与收益分配**
> 材料基础：15 部定价理论公版经典（1871–1922）+ 12 篇现代数据定价开放获取文献（2017–2023）+ 4 份中国数据要素制度原文（2022–2024）
> 一句话结论：**医疗数据定价难，不是因为"数据值多少钱"没有答案，而是因为"一条数据"根本不是一个定价单元——真正的定价单元是"面向某个用途的可交付语义包"，其边际贡献随可得样本量急剧衰减，随组合完整度急剧上升。**

# 第一部分 问题的形状

## 1.1 你观察到的现象，以及它的正确解释

一条普通门诊脱敏记录，市场价可能是几分钱；而一个罕见病的完整病例（影像 + 基因 + 多年随访 + 金标准诊断），单例可以卖到上万。**这个价差不是市场失灵，也不是"信息不对称导致的乱定价"，而是数据要素定价结构的必然结果。**

错误的解释是"高价值病例数据更稀缺所以更贵"——这只是同义反复。正确的解释要拆到价值的来源：**这两个标的根本不是同一类商品，它们的价格由两条不同的曲线决定。**

- 普通门诊记录：定价受**成本地板**约束（采集、脱敏、治理的边际成本），买方愿付受**替代品极多**压制 → 价格趋近地板。
- 罕见病完整病例：定价受**买方愿付**主导（数据直接改变一项数亿元研发决策的成功率与周期），而可得样本量极小、几乎无替代品 → 价格由用途价值决定，与采集成本无关。

**关键推论：医疗数据不能用单一"单价 × 条数"定价。必须先把数据打包成"面向用途的语义单元"，再对语义单元定价。**

## 1.2 七个结构性成因

### 成因一：组合性（超加性）——单条数据的边际贡献约等于零

这是"几分钱"的真正来源。用现代数据估值的语言（Shapley 值，见 §7.2）：对于训练一个诊断模型，从 10 万条数据里**去掉任意一条**，模型性能几乎不变。因此单条数据的 Shapley 值 ≈ 0。你能卖的从来不是"一条数据"，而是**一个能改变结果的组合**。

一个"完整病例"之所以值钱，是因为它是**最小的可用语义单元**——缺影像则无法做影像组学，缺随访则无法做结局分析，缺金标准则无法做监督学习。其价值满足**超加性**：

```
v(A ∪ B) > v(A) + v(B)
```

即各部分合起来的价值大于分开卖的价值之和。`[公版 §08]` 庞巴维克的"边际对"（marginal pairs）给出了价格形成的原型：价格落在**买方估值与卖方保留价的重叠区间**内——这也是为什么数据"没有标准价，只有区间"。`[公版 §11]` 埃奇沃思的契约曲线进一步说明：**参与者越少，价格的不确定区间越宽**——双边垄断的医疗数据交易正是这种情形。

### 成因二：价值高度依赖用途——同一份数据对不同买方差 1–3 个数量级

同一批肿瘤随访数据：
- 对**药企**（做真实世界研究、支持注册申报）：可能值数百万；
- 对**保险公司**（核保定价）：值数十万，但有合规风险；
- 对**AI 公司**（预训练）：值数万，且替代品多；
- 对**学术机构**（科研）：愿付极低，但可能通过公益路径获取。

`[公版 §06]` 杰文斯的"最后效用程度"与 `[公版 §09]` 维塞尔的"自然价值"，正是这一现象的理论原型：**价值是主观的，取决于使用场景，而非凝结在数据里的成本。** 现代文献的对应表述见 `[现代 01]` 数据定价综述中对"基于效用/基于市场/基于成本"三大定价范式的划分。

**操作含义：定价前必须先定义买方与用途（use case），否则无法定价。**

### 成因三：非竞争性 + 人为稀缺——稀缺来自"合法可得性"，不来自数据本身

数据可无限复制，边际成本趋零。若按 `[公版 §04]` 马歇尔的完全竞争逻辑推演，价格会被竞争压到边际成本（≈ 0）——这正是"数据应该很便宜"这一直觉的来源。

但医疗数据的价格并不趋零，原因是**合规约束制造了排他性**：
- 个人信息保护法要求单独同意；
- 伦理审查限定用途；
- 去标识化后仍存在再识别风险；
- 原始数据不出域（`[制度 01]` 数据二十条与后续政策确立的方向）。

**所以医疗数据的第一性原理是：稀缺性 = 合法可及性。** 一份数据的"独占价值"，等于"买方在合规前提下获得可比替代数据的难度"。

### 成因四：品质不可先验验证——体验品 + 信任品

买方在付款前无法验证质量：标注准确率、人群代表性、缺失模式、随访真实性。`[现代 10]` 提出用**数据估值模型**给数据集打分；实务上必须配质量信号机制：

- 第三方质量审计与认证（`[制度 01]` 明确培育"合规认证、安全审计、数据公证、数据保险、数据托管、资产评估"等第三方机构）；
- 小样本试算（sandbox 试跑后再定价）；
- 分级定价 + 质量保证条款（不达标退款/调价）。

### 成因五：不可逆性——泄露不可召回，定价必须含风险溢价

数据一旦出域，无法收回。风险期望损失必须进入价格：

```
C_risk = p_leak × L_identify × (1 + φ)
```

其中 `p_leak` 为泄露/再识别概率，`L_identify` 为再识别造成的损失（含患者索赔、监管处罚、声誉），`φ` 为风险厌恶系数。`[公版 §13]` 庇古的外部性分析正是这一项的理论出处：**私人成本低于社会成本时，价格信号失真，需将其内部化。**

**这解释了医疗数据定价的一个独特结构：合规成本构成价格地板，合规约束同时构成价格天花板。**（见 §8.5）

### 成因六：权利束分割——一笔钱要分给多方

一份医疗数据上叠加着多层权利：患者（个人信息权益）、医院（数据持有与加工投入）、科室与医生（采集与标注劳动）、平台（治理与流通服务）、可能有科研资助方。`[公版 §09]` 维塞尔的**归属理论（imputation）**解决的正是"多要素共同产出一个收益时如何回摊到各要素"这一问题；`[公版 §14]` 威克斯蒂德的**分配耗尽定理**进一步给出约束：**分账必须"分完且不多分"**，否则模型不自洽。

`[制度 01]` 数据二十条对此有直接要求：健全数据要素"由市场评价贡献、按贡献决定报酬"机制，按"谁投入、谁贡献、谁受益"原则，通过**分红、提成**等方式平衡各环节利益。（见 §8.2 原文要点）

### 成因七：合规成本刚性——地板是硬的

采集授权、去标识化、伦理审查、出域审计、隐私计算部署、持续合规监控——这些成本不随成交量摊薄到趋零，构成**刚性成本地板**。任何低于这个地板的"成交价"都不可持续（除非是公益或科研路径）。

## 1.3 三种交付形态，三套定价逻辑

医疗数据受"原始数据不出域"约束，定价对象往往不是数据本身：

| 交付形态 | 定价对象 | 主要定价方法 | 医疗场景适配度 |
|---|---|---|---|
| **数据集授权出域** | 数据本身（脱敏后） | 成本法 / 市场法 / 收益法（§4） | 受限：高敏感数据难出域，多为脱敏后的结构化数据 |
| **可用不可见（隐私计算 / 查询接口）** | 每一次查询、每一份统计结果 | 按查询/按结果计费 `[现代 06]` | **主战场**：原始数据不出域，合规风险最低 |
| **联合建模（联邦学习 / 多方安全计算）** | 模型收益的贡献分成 | Shapley 分账 `[现代 02][现代 08]` | **主战场**：数据方按贡献分账，`[制度 01]` 明确"按贡献决定报酬" |

**结论：医疗数据定价的工程重点不在"卖数据"，而在"卖查询"与"卖贡献"。** 因此本文件的公式体系以 §4（三法）为基础，重点落在 §5（统一价格函数）、§6（产品化分档）、§7（贡献分账）。

## L4 制度约束层：什么价格是合法的

| 约束类型 | 依据 | 对定价的硬作用 |
|---|---|---|
| 定价模式 | `[制度 01]` 数据二十条 | 公共数据按政府指导定价有偿使用；企业与个人信息数据市场自主定价 |
| 收益分配 | `[制度 01]` | 按贡献决定报酬；分红、提成等共享方式 |
| 会计确认 | `[制度 02]` 财政部暂行规定 | 数据资源确认为无形资产或存货；按成本计量；不得以评估增值调节利润 |
| 评估方法 | `[制度 03]` 中评协指导意见 | 成本法/收益法/市场法三法；质量、场景、权利为关键维度 |
| 行业推动 | `[制度 04]` 数据要素×三年行动计划 | 医疗健康为重点行业，明确数据要素价值释放方向 |
| 合规红线 | 个人信息保护法、数据安全法、GB/T 39725-2020 等 | 决定"能不能卖"——不合规的数据，价格无意义 |

**四层的关系：L1 决定价值上限，L2 决定价格如何被分割，L3 给出计算与分配的算法，L4 把结果裁剪到合法区间内。** 缺任一层，定价都会出错——只做 L3 会算出"技术正确但违规"的价格；只做 L4 会得到"合规但没人买"的价格。

# 第三部分 价值维度模型（打分卡，可算）

定价的第一步不是算钱，是**把"这份数据值多少"变成可计算的对象**。医疗数据的价值由 9 个维度决定，聚合方式必须是**几何平均（对数加权）**而不是算术平均——因为任一关键维度为零（例如合规就绪度不达标），整体价值就被清零，而算术平均会错误地保留价值。

## 3.1 九个维度

| 编号 | 维度 | 含义 | 归一化取值 | 医疗场景的度量示例 |
|---|---|---|---|---|
| d₁ | **合规就绪度** | 去标识化等级、患者授权完备度、伦理批件、出域合法性 | 0.1–1.0 | 有单独同意 + 伦理批件 + 去标识化合规 = 1.0；仅院内科研授权 = 0.3 |
| d₂ | **组合完整度** | 模态数、时序长度、随访完整率、金标准确认 | 0.1–1.0 | 仅门诊结构化字段 = 0.2；影像+病理+基因+3年随访+金标准 = 1.0 |
| d₃ | **标签质量** | 金标准比例、标注一致性（Kappa）、缺失率 | 0.1–1.0 | 病理确诊 + κ>0.85 = 1.0；ICD 编码推断 = 0.4 |
| d₄ | **稀缺度** | 同病种可比数据的可得量 | 0.1–1.0 | 常见慢病 10 万+ 例 = 0.1；罕见病全国 200 例 = 1.0 |
| d₅ | **时效性** | 数据采集时间距今天数与衰减 | 0.1–1.0 | 近 1 年 = 1.0；5 年前 = 0.4；10 年前 = 0.15 |
| d₆ | **人群代表性** | 年龄/性别/合并症/地域覆盖 | 0.1–1.0 | 单中心单科室 = 0.3；多中心分层抽样 = 0.9 |
| d₇ | **规模与统计功效** | 样本量、事件数是否满足目标分析 | 0.1–1.0 | 事件数满足预设把握度 = 1.0 |
| d₈ | **可关联性** | 能否与外部数据（死亡登记、医保、基因库）链接 | 0.1–1.0 | 有稳定患者索引键可合规链接 = 1.0 |
| d₉ | **独特性** | 与市场已有数据集的差异度（非重叠度） | 0.1–1.0 | 与公开数据集高度重叠 = 0.2；独家长期随访队列 = 1.0 |

## 3.2 聚合公式

**价值密度**（value density，几何加权平均）：

```
V = V₀ · exp( Σ_{i=1}^{9} w_i · ln(d_i) )
   其中 Σ w_i = 1，d_i ∈ [ε, 1]，ε = 0.01（防止 ln(0)）
```

参考权重（需按用途标定，下表为医疗健康数据的默认起点）：

| 维度 | 默认权重 w | 对药企/RWE | 对 AI 训练 | 对保险精算 |
|---|---|---|---|---|
| d₁ 合规就绪度 | 0.18 | 0.20 | 0.20 | 0.22 |
| d₂ 组合完整度 | 0.16 | 0.18 | 0.12 | 0.15 |
| d₃ 标签质量 | 0.14 | 0.16 | 0.20 | 0.12 |
| d₄ 稀缺度 | 0.12 | 0.14 | 0.10 | 0.08 |
| d₅ 时效性 | 0.08 | 0.06 | 0.10 | 0.12 |
| d₆ 人群代表性 | 0.10 | 0.10 | 0.14 | 0.12 |
| d₇ 规模与统计功效 | 0.08 | 0.06 | 0.08 | 0.10 |
| d₈ 可关联性 | 0.07 | 0.06 | 0.04 | 0.06 |
| d₉ 独特性 | 0.07 | 0.04 | 0.02 | 0.03 |
| 合计 | 1.00 | 1.00 | 1.00 | 1.00 |

**两个乘数**（对价格的影响是数量级的，必须单独建模）：

**稀缺度乘数 S**：可得样本量越小，单例价值越高，但关系是对数而非反比（否则会算出荒谬的天价）：

```
S = 1 + ln( N_ref / (N_avail + 1) )
   其中 N_ref = 该类数据的参考可得量基准（如该病种全国可交易样本量估计）
        N_avail = 本次交易的样本量
   下限截断：S ≥ 1
```

**组合度乘数 A**（超加性系数）：

```
A = 1 + Σ_k synergy_k
   实务估计：分别测算各模态单独的价值 v(单模态) 与整体价值 v(组合)，
   A = v(组合) / Σ v(单模态)，若 A > 1 则存在超加性
   典型区间：结构化单模态 A ≈ 1.0–1.2；多模态完整病例 A ≈ 2.0–5.0
```

`[公版 §08]` 庞巴维克的边际对理论在这里有直接解释力：**组合完整度越高，买方估值的重叠区间越宽，价格越可能落在高位。**

# 第四部分 三种定价方法与公式

`[制度 03]` 中评协《数据资产评估指导意见》明确采用成本法、收益法、市场法三条路径（并强调数据质量、应用场景、权利类型为关键考量）。医疗数据定价应**三法并行、交叉验证**，而不是任选其一——原因见 §4.4。

## 4.1 成本法：算出价格地板

成本法回答的问题是"**我至少要卖多少钱才不亏**"。它给出的是地板，不是价格。

```
重置成本（成本地板的基础）：

C_reset = ( C_collect + C_deid + C_annot + C_gov + C_audit + C_carry ) × (1 + m)

其中：
  C_collect  采集/接入成本（HIS/EMR 对接、人工录入）
  C_deid     去标识化成本（含再识别风险评估）
  C_annot    标注与金标准确认成本（含专家复核）
  C_gov      数据治理成本（标准化、质控、编码映射）
  C_audit    合规与审计成本（伦理、法务、出域审计）
  C_carry    持有成本（存储、备份、持续维护）——按持有期累计
  m          目标成本利润率
```

**风险成本**（不可省，`[公版 §13]` 庇古外部性内部化）：

```
C_risk = p_leak × L_identify × (1 + φ)

  p_leak     泄露/再识别概率（年化，按去标识化等级与数据敏感度估计）
  L_identify 再识别后果损失 = 敏感度 × 人群规模 × 可关联性 × 单位损失
  φ          风险厌恶系数（医疗数据建议 0.5–2.0）
```

**质量折价**（数据不是标准品，质量不达标必须折价）：

```
P_floor = ( C_reset × Π_j (1 − δ_j) + C_risk ) × (1 + m_min )

  δ_j 各质量缺陷折价率（缺失率高、随访脱落、标注不一致，逐项扣减）
```

**摊销与折旧**（`[制度 02]` 财政部暂行规定要求数据资源按成本计量并按规定摊销/减值）：

```
直线法：年摊销额 = C_reset / T_use
时效衰减法（更符合数据特征）：账面价值 V(t) = C_reset · exp(−λ t)
    λ = ln2 / T_half，T_half 为数据半衰期
    医疗数据经验值：结构化随访数据 T_half ≈ 3–5 年；
                    影像/基因组等稳定特征 T_half ≈ 8–15 年；
                    疫情/用药模式类 T_half ≈ 1–2 年
```

`[公版 §07]` 庞巴维克的时间偏好理论是这一项的理论出处：**未来的收益必须贴现，数据的时间价值同样如此。**

**成本法的致命局限**：对高价值数据严重低估。一个罕见病队列的重置成本可能只有几十万，但它对一项药物研发决策的价值是数千万。**成本法只能当地板，绝不能当成交价。**

## 4.2 收益法：算出买方愿付上限

收益法回答"**买方最多愿意付多少**"。它给出天花板。

```
用途价值（对买方的经济价值）：

V_use = Σ_{t=1}^{T} ΔR_t / (1 + r)^t

  ΔR_t  第 t 期由这批数据带来的增量收益
  r     贴现率（按买方加权资本成本或项目要求回报率）
  T     收益期
```

`ΔR_t` 的医疗场景口径（任选适用的）：

| 买方类型 | 增量收益来源 | 计量口径 |
|---|---|---|
| 药企 | 研发加速、成功率提升、注册申报支持 | 节省的开发时间 × 日成本 + Δ成功概率 × 项目净现值 |
| 器械/AI 企业 | 模型性能提升带来的收入 | Δ性能 × 市场规模 × 转化率 |
| 保险公司 | 精算定价精度提升、赔付率下降 | Δ赔付率 × 保费规模 |
| 医院/科研 | 科研产出、学科建设、政策补贴 | 可量化的经费与产出增量 |

**归属分解**——收益不能全算给数据：

```
V_data = η × V_use

  η = 数据要素贡献率 ∈ (0,1)
  估计方法：（a）专家打分 + 层次分析；（b）生产函数回归；
           （c）Shapley 分解（最严格，见 §7.2）
  实务经验：η 通常在 0.1–0.4 之间，很少超过 0.5
```

**买方愿付上限**——买方也要留利润，且受替代品压制：

```
P_buyer = κ × V_data

  κ = 买方价值捕获率 ∈ (0,1]，反映竞争与替代品压力
     替代品多、买方议价力强 → κ 小（0.1–0.3）
     独家数据、无替代 → κ 大（0.5–0.8）
  注意：κ 与 d₄ 稀缺度、d₉ 独特性正相关
```

`[公版 §10]` 库尔诺的垄断定价模型给出这一结构的原型：**价格由需求曲线（买方估值分布）与边际成本共同决定，边际收益等于边际成本时利润最大。** 当数据近乎独家时，卖方接近垄断者，价格趋向上限；当替代品充足时，价格趋向地板。

## 4.3 市场法：用可比交易校准

市场法回答"**同类数据实际卖了多少钱**"。它的价值在于**校准**——把成本法与收益法的结论拉回现实。

**核心工具：特征价格回归（hedonic pricing）**。把价格表示为质量维度的函数，用可比交易估计隐含价格：

```
ln P_j = β_0 + Σ_{k=1}^{9} β_k · d_{jk} + γ' X_j + ε_j

  P_j   第 j 笔可比交易的价格
  d_jk  第 j 笔交易在维度 k 上的取值（§3.1 的九维）
  X_j   其他控制变量（交付形态、授权期限、独家性、买方类型）
  β_k   维度 k 的隐含价格弹性 ← 这才是市场法真正的产出
```

**然后对新数据集预测**：

```
P_market = exp( β_0 + Σ_k β_k · d_target,k + γ' X_target ) × adj

  adj = 交易时间调整 × 买方可比性调整
```

**医疗数据可用的锚点**：各地数据交易所挂牌与成交的医疗健康数据产品（含跨地区医疗数据产品挂牌案例）、医院数据资产入表案例的评估值、公开的行业采购与授权合同。**注意：可比案例稀缺是医疗数据市场法的最大障碍**——因此必须诚实标注置信区间，而不是假装精确。

`[公版 §15]` 费雪《指数编制法》为跨期调整提供了标准工具（拉氏/帕氏指数及其几何平均即"理想指数"）：

```
I_F = √( I_L × I_P )
  I_L = Σ p_t q_0 / Σ p_0 q_0   （拉氏：基期数量加权）
  I_P = Σ p_t q_t / Σ p_0 q_t   （帕氏：当期数量加权）
  I_F = 费雪理想指数，用于数据资产年度重估与跨期可比
```

## 4.4 三法交叉验证

```
最终价格区间：
  下界 = max( P_floor , P_market_low )
  上界 = min( P_buyer , P_market_high , P_regulatory_cap )
  成交价 P* = 下界 + θ × (上界 − 下界)，θ 为卖方议价力（§5.3）
```

| 情形 | 诊断 | 处置 |
|---|---|---|
| 三法结果接近 | 市场成熟、定价可信 | 取中位，正常交易 |
| 成本法 ≪ 收益法 | 典型的高价值数据（医疗常态） | 按收益法定价，成本法仅作地板；**警惕贱卖** |
| 成本法 > 收益法 | 数据无人要或成本失控 | 暂缓交易，重新定义用途或降本 |
| 市场法区间极宽 | 可比交易稀缺（医疗常态） | 按 §6 分档定价，缩小单笔风险暴露 |
| 收益法 ≫ 制度上限 | 合规风险 | 回到 §8，检查定价模式与用途合法性 |

# 第五部分 统一价格函数：为什么"几分钱"与"上万"能共存

前四部分分别算出了地板、天花板和市场参考。这一部分把它们合成**一个价格函数**，并用两个算例展示：同一个函数如何同时产出"几分钱/条"和"上万元/例"。

## 5.1 主公式

```
                        ┌─────────────────────────────────────────┐
                        │  P* = 下界 + θ × (上界 − 下界)          │
                        └─────────────────────────────────────────┘

其中：
  下界 = max( P_floor , P_market_low )
  上界 = min( P_buyer , P_market_high , P_regulatory_cap )

  P_floor  = ( C_reset · Π(1−δ_j) + C_risk ) · (1 + m_min )          ← §4.1
  P_buyer  = κ · η · Σ_t ΔR_t / (1+r)^t                              ← §4.2

  且两者都随价值密度与两个乘数调整：
  P_floor ← P_floor × (V/V_ref)^{α}
  P_buyer ← P_buyer × (V/V_ref)^{α} × S × A
```

**这个函数解释了你观察到的全部现象**：价格差 6 个数量级，来自三个乘法项的数量级差异——`S`（稀缺度乘数）、`A`（组合度乘数）、`ΔR`（用途增量收益）。

## 5.2 数量级从哪来：拆解 6 个数量级

| 因子 | 普通门诊记录（10 万条打包） | 罕见病完整病例（单例） | 数量级差 |
|---|---|---|---|
| ΔR（用途增量收益） | 对诊断模型贡献 ≈ 0（被 10 万条中其他记录替代） | 直接支撑一项研发决策，不可替代 | ×10³ – ×10⁴ |
| S（稀缺度） | N_avail ≈ 10 万 → S ≈ 1 | N_avail ≈ 全国 200 例 → S ≈ 1+ln(1000/201) ≈ 2.6 | ×2 – ×5 |
| A（组合度） | 单模态结构化，A ≈ 1.0 | 影像+基因+随访+金标准，A ≈ 3–5 | ×3 – ×5 |
| κ（捕获率） | 替代品多 → 0.1 | 独家 → 0.6 | ×6 |
| η（贡献率） | 0.05（数据只是原料之一） | 0.35 | ×7 |
| **合计** | — | — | **≈ ×10⁵ – ×10⁶** |

**关键洞察：主导项是 ΔR（边际贡献），不是"数据条数"。** 这正好对应 `[公版 §06]` 杰文斯的"最后效用程度"——**决定价值的是边际上的那一单位，而不是总量**；也对应 `[公版 §09]` 维塞尔的归属问题——**价值要归到"对结果的贡献"，而不是归到"数据的存在"。**

## 5.3 议价力 θ 的决定因素

`[公版 §11]` 埃奇沃思证明：**参与者越少，契约（价格）的不确定区间越宽**。这直接给 θ 的含义：

```
θ = f( 替代品可得性 , 买方数量 , 时间压力 , 信息优势 )

  替代品越少      → θ 越大（卖方强）
  潜在买方越多    → θ 越大
  卖方越急(资金/合规压力) → θ 越小
  买方越懂数据质量 → θ 越小
```

**实务规则**：
- θ 无法精确测量，用**区间报价**而非单点报价（这本身就是埃奇沃思理论的实务含义）；
- 独家数据 θ ≈ 0.6–0.8；通用数据 θ ≈ 0.1–0.3；
- 数据交易所挂牌可以外生提高 θ（公开竞价）。

## 5.4 算例 A：10 万条普通门诊脱敏记录

```
假设：
  N_avail = 100,000 条，单模态结构化字段，近 2 年采集
  d1 合规就绪=0.8  d2 组合完整=0.25  d3 标签质量=0.4  d4 稀缺=0.1
  d5 时效=0.85     d6 代表性=0.3    d7 规模=0.7     d8 可关联=0.3  d9 独特=0.2
  权重取默认：0.18,0.16,0.14,0.12,0.08,0.10,0.08,0.07,0.07

计算：
  Σ w·ln d = 0.18·ln0.8 + 0.16·ln0.25 + 0.14·ln0.4 + 0.12·ln0.1
           + 0.08·ln0.85 + 0.10·ln0.3 + 0.08·ln0.7 + 0.07·ln0.3 + 0.07·ln0.2
           = -0.0402 -0.2218 -0.1283 -0.2763 -0.0130 -0.1204 -0.0285 -0.0843 -0.1127
           = -1.0255
  V = V0 × exp(-1.0255) = 0.359 V0        （V0 取同用途基准数据集）

  稀缺度乘数 S = 1 + ln(100000/100001) ≈ 1.00（可得量充足，无稀缺溢价）
  组合度乘数 A ≈ 1.0（单模态）

成本地板：
  C_collect 0.3 元/条 + C_deid 0.2 + C_annot 0.1 + C_gov 0.15 + C_audit 0.05
  = 0.8 元/条 × 100,000 = 8 万元
  C_carry（3 年存储维护）≈ 3 万元
  C_risk = p_leak 0.002 × L 50 万 × (1+1.0) = 0.2 万元
  C_reset = (8 + 3) × (1+0.15) + 0.2 ≈ 12.85 万元
  质量折价 δ：缺失率折 10%，代表性不足折 15% → Π(1−δ) = 0.765
  P_floor = 12.85 × 0.765 ≈ 9.8 万元   →   0.98 元/条

买方愿付：
  ΔR：买方为 AI 公司，模型性能提升等价收益 ≈ 80 万元
  η = 0.05 → V_data = 4 万元
  κ = 0.3（替代品多）→ P_buyer = 1.2 万元  ← 低于成本地板！

诊断：该交易在成本法下不可行 —— 这正是"卖原始数据不赚钱"的数学表达。
处置：改为按查询计费或联合建模分账（§1.3），
     此时定价对象不再是"数据"，而是"结果"和"贡献"。
     若坚持打包出售，成交价将趋近地板 ≈ 1 元/条，
     折算到单条远低于 1 元 —— 这就是"几分钱一条"的来源。
```

## 5.5 算例 B：罕见病完整病例（单例）

```
假设：
  N_avail = 200 例（全国可交易量估计 N_ref = 1000）
  组合：影像 + 基因 + 5 年随访 + 金标准确诊
  d1 合规就绪=0.9  d2 组合完整=0.95  d3 标签质量=0.95  d4 稀缺=0.95
  d5 时效=0.8      d6 代表性=0.6     d7 规模=0.3     d8 可关联=0.8  d9 独特=0.9

计算：
  Σ w·ln d = 0.18·ln0.9 + 0.16·ln0.95 + 0.14·ln0.95 + 0.12·ln0.95
           + 0.08·ln0.8 + 0.10·ln0.6 + 0.08·ln0.3 + 0.07·ln0.8 + 0.07·ln0.9
           = -0.0190 -0.0082 -0.0072 -0.0062 -0.0178 -0.0511 -0.0963 -0.0156 -0.0074
           = -0.2288
  V = V0 × exp(-0.2288) = 0.795 V0        （接近基准数据集的高质量水平）

  稀缺度乘数 S = 1 + ln(1000/201) ≈ 1 + 1.605 ≈ 2.61
  组合度乘数 A ≈ 3.5（多模态超加性）
  → 综合乘数 S × A ≈ 9.1

买方愿付（药企，用于罕见病药物研发与注册申报）：
  ΔR：加速研发 8 个月 × 月成本 200 万 = 1600 万
      + 成功概率提升 0.5% × 项目净现值 20 亿 = 1000 万
      → ΔR ≈ 2600 万元（可在 T=5 年分期实现，r=10% 折现后 ≈ 1970 万元）
  η = 0.35 → V_data ≈ 690 万元
  κ = 0.6（独家、无替代）→ P_buyer ≈ 414 万元（整队列 200 例）

  → 折合单例上限 ≈ 2.07 万元/例   ← "上万"的来源

成本地板：
  C_reset（单例完整采集+多模态治理+基因测序+随访）≈ 1.5 万元
  C_risk 因高敏感（基因+罕见病）显著：p_leak 0.01 × L 500 万 × 2.0 = 10 万元
  P_floor ≈ (1.5 + 10) × 1.15 ≈ 13.2 万元/例   ← 注意：单例地板高于整队列折合上限

冲突与处置：
  单例地板 13.2 万 > 单例上限 2.07 万，但整队列比较是可行的
  （地板按单例计含全额风险成本，整队列交易的风险成本不随例数线性增长）。
  因此正确做法是：整队列打包 + 分档授权 + 风险成本按交易而非按例计提。
  成交价区间：单例 1.2 万 – 2.0 万元；整队列 240 万 – 400 万元。
```

**这两个算例给出最重要的方法论结论**：
1. **定价单元必须与交付形态匹配**——按"条"定价会把高价值数据的价值切碎；
2. **风险成本按交易计提，不按记录数计提**——否则小规模高价值数据的定价会被完全扭曲；
3. **同一条公式可以产出 6 个数量级的价格差异**，只要参数取值不同——这证明差异是结构性的，不是市场混乱。

# 第六部分 产品化：分档与捆绑

## 6.1 版本划分（versioning）

`[公版 §13]` 庇古的价格歧视三级分类是分档定价的原始理论框架：

| 庇古分类 | 含义 | 医疗数据场景的对应 |
|---|---|---|
| 一级 | 对每个买方按其愿付定价 | **高风险**：对罕见病患者/小样本群体差别定价，存在伦理与合规风险，应避免 |
| 二级 | 按购买量/使用量分档（自选择） | **推荐**：按查询次数、样本量、随访年限分档 |
| 三级 | 按买方群体分档 | **可用**：药企/器械/保险/科研/公益不同档 |

**分档设计公式**（档位价格比与自选择约束）：

```
档位 L_1 … L_K，价格 P_1 < … < P_K，价格比 r = P_{k+1}/P_k（建议 2–3 倍）
约束（激励相容）：高需求买方不会伪装成低需求买方：
    u(高类型, 买高档) ≥ u(高类型, 买低档)
    u(低类型, 买低档) ≥ u(低类型, 买高档)
实务判据：若某档位连续两期无人购买，说明档位划分与真实需求分布不匹配。
```

**医疗数据的推荐分档维度**（正交，避免一维堆量）：

| 档位 | 内容 | 典型买方 |
|---|---|---|
| 聚合统计层 | 去标识化统计结果、频数分布 | 科研、政策研究 |
| 队列摘要层 | 分病种队列的特征与结局摘要 | 保险精算、器械 |
| 完整病例层 | 多模态完整病例（可用不可见） | 药企 RWE、AI 训练 |
| 联合建模层 | 参与联邦建模并分账 | 药企、AI 公司（**最合规、最可持续**） |

## 6.2 捆绑（bundling）

捆绑是解决"单条数据不值钱、组合才值钱"的直接工具：

```
捆绑定价区间：
  max_i(w_i)  ≤  P_bundle  ≤  Σ_i w_i

  w_i = 买方对第 i 个组成部分的独立愿付
  需求负相关（互补）→ 捆绑价值趋近 Σ w_i（高）
  需求正相关（替代）→ 捆绑价值趋近 max w_i（低）

医疗数据的组合天然互补：
  影像 + 病理 + 基因 + 随访 + 结局 → 强互补 → 捆绑溢价高
  同一病种的多中心数据 → 弱互补 → 捆绑溢价低（但仍提升统计功效）
```

**实务含义**：把"单医院单模态"打包成"多中心多模态队列"是价值跃升的主要手段——这同时解决了统计功效（d₇）与代表性（d₆）两个维度。

## 6.3 权利束定价

数据的价值不只取决于内容，还取决于**卖的是什么权利**：

```
P = P_base × Π_m m_factor

  m1 使用范围（院内科研 / 商业研发 / 可再许可）
  m2 期限（1 年 / 3 年 / 永久）
  m3 独家性（非独家 / 领域独家 / 完全独家）
  m4 交付形态（数据集 / 查询接口 / 联合建模）
  m5 是否可再分发（通常禁止，禁止应降价而非加价）

经验倍数（供标定，需按项目修正）：
  商业研发 vs 院内科研：×3 – ×10
  领域独家 vs 非独家：×2 – ×5
  永久 vs 1 年：×2 – ×4
```

**常见错误**：把"永久 + 完全独家 + 可再分发"三项叠加卖出，等于把数据的全部未来价值一次性贴现掉。`[公版 §07]` 庞巴维克关于时间与资本价值的分析提示：**一次卖断等价于放弃全部未来收益流，必须按现值总和定价，而不是按单次使用定价。**

# 第七部分 数据要素收益分配（分账）

## 7.1 制度要求

`[制度 01]` 数据二十条在收益分配部分提出（要点）：

- 健全数据要素**由市场评价贡献、按贡献决定报酬**机制；
- 按**"谁投入、谁贡献、谁受益"**原则，保护各参与方的投入产出收益；
- 推动数据要素收益向**数据价值和使用价值的创造者**合理倾斜；
- 通过**分红、提成**等多种收益共享方式，平衡采集、加工、流通、应用各环节主体之间的利益分配。

**这三条直接决定了分账模型的形状**：必须基于"贡献"，必须覆盖全链条环节，必须可执行（分红/提成）。

## 7.2 贡献度量：Shapley 值

`[公版 §09]` 维塞尔的归属理论给出问题，`[公版 §14]` 威克斯蒂德的分配耗尽定理给出约束，现代文献给出算法：

```
Shapley 值（`[现代 02][现代 08]`）：
  φ_i = Σ_{S ⊆ N\{i}} [ |S|! (n−|S|−1)! / n! ] × [ v(S ∪ {i}) − v(S) ]

  N      参与方集合（各医院、各数据源、标注方、平台）
  v(S)   子集 S 的联盟价值（如：用 S 中数据训练的模型性能）
  φ_i   第 i 方的边际贡献均值

性质（正是分账需要的）：
  · 有效性：Σ φ_i = v(N)          → 分完且不多分（对应分配耗尽定理）
  · 对称性：贡献相同则所得相同     → 符合"按贡献决定报酬"
  · 零贡献者得零                   → 无投入不分账
  · 可加性：可分项计算             → 支持分期、分场景结算
```

**计算可行性**（n 个参与方需要 2ⁿ 次评估，n>15 时不可行）：

| 近似方法 | 原理 | 适用 `[现代]` |
|---|---|---|
| 蒙特卡洛采样 | 随机排列采样估边际贡献 | 通用 |
| TMC（截断蒙特卡洛） | 只算小规模子集 | `[现代 02]` |
| β-Shapley | 降噪、稳定估值 | `[现代 11]` |
| 分布型框架 | 给出估值分布而非点估计 | `[现代 12]` |

**医疗场景的前提**：Shapley 需要能反复重训模型来评估子集性能。若做不到（数据不能出域、训练成本高），退化为**代理指标分账**（§7.3）。

## 7.3 可执行的分账公式

```
交易总收益 R_deal 按三层分配：

第一层 · 贡献分配（主体部分，建议 60–75%）
  R_i = R_deal × ρ × ( η_i / Σ_j η_j )

  η_i = 第 i 方的贡献系数，可由以下任一给出：
        (a) Shapley 值 φ_i（最严格，需可重训）
        (b) 代理评分：η_i = QualityScore_i × VolumeShare_i × Uniqueness_i
        (c) 合同约定权重

第二层 · 投入补偿（成本回收，建议 15–25%）
  R_i^cost = R_deal × σ × ( C_i / Σ_j C_j )
  C_i = 第 i 方的实际投入成本（采集、脱敏、标注、治理）

第三层 · 公共与患者回馈（建议 5–15%，医疗场景强烈建议保留）
  R^public = R_deal × τ
  用途：患者知情同意补偿机制、医院公益服务、数据信托、
        罕见病患者组织回馈 —— 该项虽非法律强制，
        但显著降低合规与声誉风险，且直接对应政策中"更加关注
        公共利益和相对弱势群体"的导向。

约束：ρ + σ + τ = 1
```

**分账算例**（一家药企支付 300 万采购多中心罕见病队列）：

```
参与方：A 医院（120 例，投入 80 万）、B 医院（60 例，投入 50 万）、
        C 医院（20 例，投入 25 万）、平台方（治理与合规，投入 30 万）

贡献系数（用代理评分，因数据不可出域无法重训）：
  A：质量 0.9 × 量 0.6 × 独特 0.8 = 0.432
  B：0.85 × 0.3 × 0.75 = 0.191
  C：0.9 × 0.1 × 0.95 = 0.0855   （量少但极独特）
  平台：0.95 × 1.0 × 1.0 = 0.95   （合规与流通能力，全队列必需）
  Σ = 1.6585

取 ρ=0.70，σ=0.20，τ=0.10：

贡献分配（210 万）：
  A：210 × 0.432/1.6585 = 54.7 万
  B：210 × 0.191/1.6585 = 24.2 万
  C：210 × 0.0855/1.6585 = 10.8 万
  平台：210 × 0.95/1.6585 = 120.3 万
投入补偿（60 万）：
  A：60 × 80/185 = 25.9 万   B：16.2 万   C：8.1 万   平台：9.7 万
公共回馈（30 万）：患者组织 / 公益基金

合计：
  A：80.6 万   B：40.4 万   C：18.9 万   平台：130.0 万   公共：30 万
```

**注意 C 医院的情形**：仅 20 例，若按"条数"分账只得很小一块；但其稀缺度极高（d₄=0.95），在贡献评分中因此获得不低权重。**这正是"按贡献而非按条数分配"的制度意图，也是 §3 中把稀缺度列为独立维度的原因。**

# 第八部分 制度约束层：什么价格是合法的

医疗数据定价与普通商品定价最大的差别：**价格必须在制度划定的合法区间内**。这一部分给出四条硬约束。

## 8.1 定价模式：谁能定什么价

`[制度 01]` 数据二十条明确（原文要点）：

> 支持探索多样化、符合数据要素特性的定价模式和价格形成机制，推动用于数字化发展的**公共数据按政府指导定价有偿使用**，**企业与个人信息数据市场自主定价**。

**翻译成操作规则**：

| 数据类型 | 定价模式 | 医疗场景 |
|---|---|---|
| 公共数据（政府/公共机构持有，用于数字化发展） | **政府指导定价**有偿使用 | 区域健康信息平台数据、公共卫生监测数据 |
| 企业数据 | **市场自主定价** | 药企自有临床数据、器械企业数据 |
| 个人信息数据 | **市场自主定价**，但受个人信息保护法强约束 | 医院持有的患者数据（**必须单独同意 + 去标识化**） |

**注意**：医院数据同时具备"公共机构持有"与"个人信息"双重属性，定价模式需按**数据来源与授权基础**分别判断，不能一概而论。这是医疗数据定价最容易踩的合规坑。

## 8.2 收益分配：怎么分才合规

`[制度 01]` 关于收益分配的核心要求（原文要点，见 §7.1）：健全"由市场评价贡献、按贡献决定报酬"机制；按"谁投入、谁贡献、谁受益"原则；收益向数据价值和使用价值的创造者合理倾斜；通过**分红、提成**等共享方式平衡各环节利益；发挥政府引导调节作用，更加关注公共利益和相对弱势群体。

**操作含义**：§7.3 的三层分账模型（贡献分配 + 投入补偿 + 公共回馈）不是可选项，而是对上述要求的直接工程化。

## 8.3 会计确认：入表意味着什么

`[制度 02]` 财政部《企业数据资源相关会计处理暂行规定》（财会〔2023〕11号）的核心结构：

| 要点 | 内容 |
|---|---|
| 确认路径 | 符合条件的数据资源，按用途分别确认为**无形资产**（自用）或**存货**（日常活动中持有以备出售） |
| 计量基础 | **按成本计量**（采集、加工、脱敏、治理等可直接归属的支出），不按评估值入账 |
| 后续计量 | 无形资产按规定**摊销**；使用寿命不确定的不摊销但需**减值测试**；存货按成本与可变现净值孰低 |
| 禁止项 | **不得以评估增值调节利润** |
| 披露 | 需披露数据资源的类别、规模、来源、权属、用途等 |

**对定价的三条硬约束**：
1. **成本法不是可选项**——它是会计确认的法定计量基础；
2. **评估值 ≠ 入账价值**——用收益法/市场法算出高价，不能直接进资产负债表；
3. **摊销与时效衰减必须建模**——`[公版 §07]` 庞巴维克的时间偏好理论在此处成为会计要求。

## 8.4 评估方法：三法的官方口径

`[制度 03]` 中评协《数据资产评估指导意见》（中评协〔2023〕17号）确立的框架与本文件 §4 一致，并特别强调以下考量维度（原文要点）：

- 采用**成本法、收益法、市场法**及其衍生方法；
- 需充分考虑**数据质量**（完整性、准确性、一致性、时效性等）、**应用场景**、**权利类型**（持有权/使用权/经营权等）、**成本构成**、**预期收益**与**可比交易**；
- 对数据资产的**有效期/收益期**、**折现率**、**分成率**等参数需说明确定依据。

> 本文件的 §3（九维价值模型）对应其"数据质量"要求，§4.5（符号表）覆盖其参数要求，§6.3（权利束定价）对应其"权利类型"要求。即：中评协的口径可直接映射到本文件的公式体系上。

## 8.5 医疗数据专项：合规构成地板也是天花板

医疗数据受多层规范约束（`[制度 04]` 及以下专项）：

| 规范 | 对定价的作用 |
|---|---|
| 《个人信息保护法》 | 处理敏感个人信息需**单独同意**；告知用途 → 限定可交易范围 |
| 《数据安全法》 | 数据分类分级；重要数据出境管制 |
| GB/T 39725-2020《信息安全技术 健康医疗数据安全指南》 | 健康医疗数据的分类分级与安全要求 → 决定哪一层数据可交易 |
| 伦理审查（涉及人的生命科学和医学研究伦理审查办法） | 用途限定与再同意要求 → 限制商业用途 |
| 《"数据要素×"三年行动计划（2024—2026年）》 | 医疗健康列为重点行业，鼓励数据要素价值释放（政策上行空间） |

**结构结论**（本文件最重要的实务判断）：

```
        上界 = min( 买方愿付 P_buyer , 制度上限 P_regulatory_cap )
        下界 = max( 成本地板 P_floor , 合规刚性成本 )

  医疗数据的特殊性在于：合规成本推高下界，合规限制压低上界，
  两端同时收紧 → 可成交区间比一般数据窄得多。

  因此医疗数据定价的主战场不是"把价格谈高"，
  而是"通过交付形态设计扩大合法区间"：
    数据集授权（区间窄）→ 查询计费（区间中）→ 联合建模分账（区间宽）
```

这份政策文件（`[制度 04]`）把医疗健康列为重点行业，意味着**政策方向是扩大可交易区间**——但扩大的方式是"授权运营 + 隐私计算 + 分账"，而不是"放宽个人信息交易"。定价方案必须顺着这个方向设计。

## 8.6 合规检查清单

```
□ 数据分类分级结论明确（是否含重要数据/敏感个人信息）
□ 授权链条完整（患者单独同意 / 伦理批件 / 机构授权 / 数据来源合法性）
□ 去标识化等级与再识别风险评估已做
□ 交付形态合法（原始数据出域是否被允许？是否必须可用不可见？）
□ 定价模式正确（公共数据政府指导定价 / 企业与人个数据市场自主定价）
□ 收益分配符合"按贡献决定报酬"且有书面合同
□ 入表口径与定价口径分离（评估值不直接入账）
□ 审计留痕（交易、授权、用途、分发全程可追溯）
□ 转让后用途监控与违约追责机制存在
```

# 第九部分 落地流程：八步定价法

```
第 1 步 · 定义定价单元
  明确「买方 × 用途 × 交付形态」三元组。
  ⚠ 缺任一项则无法定价。最常见的错误是从"我们有多少条数据"开始，
    而不是从"谁要用它做什么"开始。

第 2 步 · 权利与合规预审
  授权链、伦理、去标识化、可交易层级（§8.5）。
  ⚠ 不合规的数据，价格无意义 —— 这一步在算钱之前。

第 3 步 · 价值维度打分
  九维打分卡（§3.3），确定权重（按买方类型选权重表）。
  产出：V、S、A 三个核心量。

第 4 步 · 成本法算地板
  重置成本 + 风险成本 + 质量折价（§4.1）。
  产出：P_floor。

第 5 步 · 收益法算天花板
  ΔR 建模 + 归属分解 η + 捕获率 κ（§4.2）。
  产出：P_buyer。
  ⚠ 这是医疗数据最容易被忽略的一步：不做收益法 = 系统性贱卖。

第 6 步 · 市场法校准
  收集可比交易，做 hedonic 回归，得到隐含价格弹性 β_k（§4.3）。
  产出：P_market 区间 + 对前两步的校准。
  ⚠ 医疗数据可比交易稀缺，必须诚实标注置信度。

第 7 步 · 定档与定价
  三法交叉（§4.4）→ 价格区间 → 分档与捆绑设计（§6）→
  议价力 θ 定成交价（§5.3）。
  产出：报价单（分档 × 权利束）。

第 8 步 · 分账与留痕
  三层分账（§7.3）+ 合同 + 审计存证 + 后续用途监控。
  产出：可审计的收益分配方案。
```

## 9.1 快速自检：定价是否可信

| 检查项 | 可信 | 不可信（危险信号） |
|---|---|---|
| 定价依据 | 三法交叉 | 只有成本加成 / 只有一个"市场价" |
| 卖方视角 | 收益法给出上限 | 只算成本，从不估买方收益 |
| 定价单元 | 语义包（病例/队列/查询） | 按"条"报价 |
| 权利范围 | 权利束明确分档 | 一次性全部权利卖断 |
| 风险成本 | 显式计入 | 忽略泄露与再识别风险 |
| 时效 | 有衰减率 λ | 假设数据永不过期 |
| 分账 | 按贡献（含稀缺度） | 按条数平分 |
| 会计 | 定价与入表口径分离 | 用评估值直接入账 |
| 合规 | 有授权与用途限定 | 默认"脱敏了就能卖" |

# 第十部分 常见陷阱（对应经典理论中的原始错误）

| 陷阱 | 表现 | 理论根源 | 处置 |
|---|---|---|---|
| **成本加成定高价值数据** | 罕见病队列按采集成本定价，几十万卖掉实际值数千万 | 混淆了 `[公版 §01]` 斯密的 use value 与 exchange value——使用价值远高于成本 | 成本法只作地板，强制做收益法 |
| **按"条"定价** | 单条几分钱，高价值病例的价值被切碎 | 忽略 `[公版 §06]` 杰文斯的边际效用——价值在边际贡献，不在计数 | 改为按语义单元（病例/队列/查询）定价 |
| **忽略组合超加性** | 把多模态数据拆开单卖，总价远低于打包 | `[公版 §08]` 庞巴维克边际对：组合越完整，买方估值区间越高 | 捆绑定价（§6.2） |
| **假设数据永不贬值** | 用采集成本长期挂账 | `[公版 §07]` 庞巴维克时间偏好：未来收益须贴现 | 引入衰减率 λ 与摊销（§4.1） |
| **单一"市场价"幻觉** | 引用某平台单个成交价作为定价依据 | `[公版 §11]` 埃奇沃思：双边垄断下价格本就是区间 | 用区间报价，做 hedonic 校准 |
| **对弱势群体一级价格歧视** | 对罕见病患者数据按愿付极限定价 | `[公版 §13]` 庇古一级歧视在福利上的争议 | 避免一级歧视；用二级/三级分档 + 公共回馈（§7.3） |
| **忽略外部性与风险** | 价格不含泄露期望损失 | `[公版 §13]` 庇古外部性内部化 | 显式计入 C_risk（§4.1） |
| **分账按条数平分** | 20 例极稀缺数据只分到零头 | `[公版 §09]` 维塞尔归属：价值归到贡献而非存量 | 按贡献分账，稀缺度入权重（§7.3） |
| **分账分不完或有剩余** | 各方分配之和 ≠ 交易总额 | `[公版 §14]` 威克斯蒂德分配耗尽定理 | 用 Shapley 的有效性性质保证（§7.2） |
| **把"永久独家"当常规卖出** | 一次性耗尽数据全部未来价值 | `[公版 §07]` 时间价值 | 权利束分档（§6.3） |
| **用评估值直接入账** | 报表虚增 | `[制度 02]` 财政部规定明确禁止以评估增值调节利润 | 定价与入表口径分离（§8.3） |
| **先定价后审合规** | 谈成才发现不能出域 | `[制度 01]`-`[制度 04]` 合规前置 | 八步法第 2 步前置合规（§9） |

## D.3 一页速查

```
医疗数据定价 = 合法区间内的议价结果

  合法区间上界 = min( 买方愿付 , 制度上限 )
  合法区间下界 = max( 成本地板 , 合规刚性成本 )
  成交价       = 下界 + θ × (上界 − 下界)

  买方愿付 = κ · η · Σ ΔR_t /(1+r)^t · S · A
  成本地板 = ( 重置成本 × 质量折价 + 风险成本 ) × (1+最低毛利)

  为什么"几分钱"：ΔR ≈ 0（被替代）、S ≈ 1、A ≈ 1、κ 小
  为什么"上万"：  ΔR 大（不可替代）、S × A 高、κ 大

  分账 = ρ×贡献 + σ×投入 + τ×公共   （ρ+σ+τ = 1）
  贡献用 Shapley 或代理评分；稀缺度必须进权重
```
