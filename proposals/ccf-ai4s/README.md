# CCF 政策建议提案（公文版）

《以可信科学数据基础设施支撑“人工智能+科学技术”——关于布局科学数据可信空间、服务第五科研范式的建议》
正文源文件与版式定义。内容与仓库根目录 `CCF-可信科学数据空间-支撑AI4S提案2.pdf` 一致，
仅调整排版（该版本已弱化单一案例的商业指向）。

## 构建

```bash
./build.sh                 # 输出到 ../../CCF-可信科学数据空间-支撑AI4S提案2（公文版）.pdf
./build.sh /path/out.pdf   # 指定输出路径
```

依赖 `uv`（首次运行自动拉取 weasyprint 70 与 pypdf），无需本机装 Python 环境。

## 文件

| 文件 | 作用 |
| --- | --- |
| `proposal.html` | 全文内容（唯一内容源，改字只改这里） |
| `proposal.css` | 版式：A4、宋体正文/黑体标题、三线表、公文页码 |
| `merge.py` | 封面 + 正文合并，保留书签与元数据 |
| `build.sh` | 两趟渲染 + 合并 |

## 版式约定

- **页面**：A4，上 32mm / 下 28mm / 左 28mm / 右 26mm；正文 12pt，行距 1.72，首行缩进 2 字。
- **标题**：一级（一、二、……）黑体 15pt；二级（（一）（二）……）黑体 12.5pt；三级（建议一……）宋体加粗。
  不使用分隔线，靠字号与字重区分层级，符合公文观感。
- **表格**：三线表（顶线 1.2pt、栏目线 0.6pt、底线 1.2pt），表题居中置于表上方，编号为「表 1」「表 2」。
- **脚注**：正文脚注用 CSS `float: footnote` 落到当页页脚，带细分隔线；正文标注为上标序号。
- **页码**：页脚居中「— 1 —」，封面不计页码。
- **封面**：文种标识 + 标题 + 副标题 + 提案人/主送/抄送 + 日期，无红头、无彩色。
- **书签**：由标题自动生成，PDF 侧栏可直接跳章节。

## 与 `提案2.pdf` 的差异（仅排版）

1. 正文由两端对齐的宋体小四统一为 12pt/1.72，页边距改为公文比例；
2. FAIR 表与建议表改为三线表，新增表题与固定列宽，消除挤压换行；
3. 圆点列表改为编号 + 悬挂缩进（公文少用「•」）；
4. 「案例边界说明」独立成带框注块，位置稳定不被分页拆开；
5. 原内联的「【注】……」改为真正的页脚脚注；
6. 参考文献改为悬挂缩进的「[1]……」编号体例；括号数字（如〔2024〕119号）加 `nobr` 防止跨行断字；
7. 全文 9 页→8 页，页码从正文起算。

## 字体

当前用 macOS 自带的 **Songti SC / Noto Serif CJK SC**（宋体）与
**Noto Sans CJK SC / Heiti SC**（黑体）。若目标环境装了方正字体，把 `proposal.css`
里 `--font-body` / `--font-hei` 换成 `FangSong_GB2312` / `SimHei` 即为标准公文观感，
不改任何标记。

## 内容改动

除排版外，正文与 `提案2.pdf` 完全一致；唯一差异是把「（见本节末注）」改为脚注序号，
注文内容原样保留在当页页脚。
